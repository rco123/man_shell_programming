crontab

cron을 이용하여 부팅 시 자동으로 실행되는 스크립트인 cronapp.sh를 처음부터 작성하고, 이 스크립트가 /home/jetson/cronapp.log 파일에 순차적으로 로그를 기록하도록 하는 전체 절차와 예제입니다.

1. cronapp.sh 스크립트 작성

이 스크립트는 로그인 인터랙티브 모드로 실행되어 사용자의 초기화 파일(.bashrc 등)이 로드된 상태에서, 시작 시 초기 로그를 기록한 후 무한 루프로 주기적으로 현재 날짜와 시간을 기록합니다.

/home/jetson/cronapp.sh

#!/bin/bash
# cronapp.sh - 부팅 시 자동 실행되는 예제 앱

LOGFILE="/home/jetson/cronapp.log"

# 초기 로그 기록
echo "===================" >> "$LOGFILE"
echo "Cron app started at $(date)" >> "$LOGFILE"
echo "Current environment:" >> "$LOGFILE"
env >> "$LOGFILE"
echo "===================" >> "$LOGFILE"

# 만약 checkval 환경변수가 설정되어 있으면 출력, 없으면 메시지 출력
if [ -n "$checkval" ]; then
    echo "checkval is $checkval" >> "$LOGFILE"
else
    echo "checkval is not exist" >> "$LOGFILE"
fi

# 무한 루프: 10초마다 현재 날짜와 시간을 로그에 기록
while true; do
    echo "Current date: $(date)" >> "$LOGFILE"
    sleep 10
done

스크립트 설정 단계

  1. 위 코드를 /home/jetson/cronapp.sh 파일로 저장합니다.
  2. 터미널에서 실행 권한을 부여합니다. 
    chmod +x /home/jetson/cronapp.sh

2. Cron 작업 등록

cron에서 부팅 시 자동 실행하도록 설정하려면, crontab에 @reboot 항목을 추가합니다.
여기서는 bash를 로그인(-l) 및 인터랙티브(-i) 모드로 실행해서, 사용자의 초기화 파일(.bashrc 등)이 로드된 상태에서 스크립트가 실행되도록 합니다.

Crontab 설정 절차

  1. 터미널에서 jetson 사용자로 crontab 편집기를 엽니다. 
    crontab -e
  2. 편집기에서 아래와 같이 한 줄을 추가합니다. 
    @reboot /bin/bash -l -i -c '/home/jetson/cronapp.sh'
  3. -l 옵션: 로그인 셸로 실행하여 /etc/profile, ~/.bash_profile 등을 먼저 읽습니다.
  4. -i 옵션: 인터랙티브 모드로 실행하여, .bashrc 등의 인터랙티브 초기화 파일도 로드합니다.

  5. -c 옵션: 뒤따르는 명령어(여기서는 /home/jetson/cronapp.sh)를 실행합니다.

  6. 저장 후 crontab이 적용되면, 시스템 재부팅 시 해당 스크립트가 자동으로 실행됩니다.

3. 동작 확인 및 로그 파일 확인

  • 시스템을 재부팅한 후, /home/jetson/cronapp.log 파일을 열어 로그가 정상적으로 기록되는지 확인합니다.
  • 로그 파일에는 스크립트 시작 시간, 환경 변수 목록, checkval 변수의 상태 및 주기적으로 기록되는 현재 날짜와 시간이 포함되어 있어야 합니다.

이와 같이 설정하면, 부팅 시 cron이 /bin/bash -l -i -c '/home/jetson/cronapp.sh' 명령어를 실행하여, 사용자 환경이 로드된 상태에서 cronapp.sh 스크립트가 자동으로 실행되고, /home/jetson/cronapp.log 파일에 로그가 기록됩니다.
