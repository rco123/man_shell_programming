systemctl (USER)

Jetson 부팅 시 "jetapp" 자동 실행 설정 및 간단한 App 예제 (사용자 디렉토리 활용) 에 대한 설명

jetson 사용자가 부팅 시 "/home/jetson/jetapp.sh" 스크립트를 자동으로 실행하도록 설정하는 전체 과정을 순서대로 설명합니다. 이 예제에서는 스크립트가 "/home/jetson/jetapp.log" 파일에 로그를 남기며, 추가로 "/home/jetson/jet_env" 파일을 사용하여 환경 변수를 로드하도록 구성합니다.

부팅 시 자동으로 실행할 간단한 앱(jetapp.sh)을 먼저 작성한 후, 이를 systemd 서비스로 등록하여 부팅 시 자동 실행되도록 설정하는 과정을 단계별로 설명합니다.
특히, 스크립트 파일과 로그 파일은 모두 /home/jetson 디렉토리에 위치하며, 환경 변수는 별도의 환경 파일(/home/jetson/jet_env)을 통해 설정합니다.

1. 간단한 App 예제 작성

다음은 간단한 Bash 스크립트 예제입니다. 이 스크립트는 실행되면 /home/jetson/jetapp.log 파일에 시작 시간, 환경 변수 값(예: checkval) 및 10초마다 현재 시간을 기록합니다.

/home/jetson/jetapp.sh

#!/bin/bash
# jetapp.sh - 간단한 예제 앱

LOGFILE="/home/jetson/jetapp.log"

# 환경 변수 출력 (jet_env 파일을 통해 설정한 값이 반영됨)
echo "===================" >> "$LOGFILE"
echo "Current environment:" >> "$LOGFILE"
env >> "$LOGFILE"
echo "===================" >> "$LOGFILE"

if [ -n "$checkval" ]; then
    echo "checkval is $checkval" >> "$LOGFILE"
else
    echo "checkval is not exist" >> "$LOGFILE"
fi

# 시작 시 기록
echo "JetApp started at $(date)" >> "$LOGFILE"

# 무한 반복하여 현재 시간 기록
while true; do
    echo "JetApp is running at $(date)" >> "$LOGFILE"
    sleep 10
done

스크립트 배포 및 실행 권한 부여

  1. 위 코드를 /home/jetson/jetapp.sh 파일로 저장합니다.
  2. 파일에 실행 권한을 부여합니다.
chmod +x /home/jetson/jetapp.sh

2. 환경 변수 파일 (jet_env) 샘플 작성

환경 변수 파일은 systemd가 서비스를 시작할 때 필요한 환경 변수를 로드하는 용도로 사용됩니다.
예를 들어, 아래와 같이 /home/jetson/jet_env 파일을 작성할 수 있습니다.

/home/jetson/jet_env

# /home/jetson/jet_env - 환경 변수 설정 파일
checkval=hello
# 추가 환경 변수를 아래와 같이 정의할 수 있습니다.
ANOTHER_VAR=sample_value

주의: EnvironmentFile은 각 줄마다 KEY=value 형식으로 작성해야 하며, 한 줄에 여러 변수를 나열하면 올바르게 파싱되지 않습니다.

3. 서비스 방식에 따른 설정 및 부팅 시 자동 실행

작성한 스크립트와 환경 변수 파일을 부팅 시 자동 실행하도록 systemd 서비스로 등록하는 방법을 두 가지 방식(시스템 서비스와 사용자 서비스)으로 설명합니다.

3-1. 사용자 서비스 방식

사용자 단위 서비스는 jetson 사용자의 홈 디렉토리 내에서 관리되며, 사용자가 직접 제어할 수 있습니다.
기본적으로 사용자가 로그인되어야 실행되므로, 로그인 없이 부팅 시 실행하려면 lingering 설정을 추가해야 합니다.

3-1-1. 사용자 단위 서비스 유닛 파일 작성

jetson 사용자의 홈 디렉토리 내 ~/.config/systemd/user/ 폴더에 서비스 유닛 파일을 생성합니다. 디렉토리가 없으면 생성합니다.

mkdir -p ~/.config/systemd/user/

그리고 ~/.config/systemd/user/jetapp.service 파일을 다음과 같이 작성합니다.

[Unit]
Description=JetApp Service

[Service]
ExecStart=/home/jetson/jetapp.sh
Restart=always
EnvironmentFile=/home/jetson/jet_env

[Install]
WantedBy=default.target

3-2-2. 사용자 서비스 활성화 및 부팅 시 자동 실행 설정

터미널에서 아래 명령어를 실행합니다.

systemctl --user daemon-reload
systemctl --user enable jetapp.service
systemctl --user start jetapp.service

3-2-3. 로그인 없이 부팅 시 자동 실행(lingering) 설정

사용자가 로그인하지 않아도 서비스가 실행되도록 하려면 관리자 권한으로 lingering을 활성화합니다.

sudo loginctl enable-linger jetson

취소를 하는 경우는 

sudo loginctl disable-linger jetson

4. 전체 요약

  1. 앱 예제 작성 및 배포
  2. /home/jetson/jetapp.sh 파일에 스크립트를 작성하고, 로그는 /home/jetson/jetapp.log에 기록

  3. chmod +x /home/jetson/jetapp.sh 명령어로 실행 권한 부여

  4. 환경 변수 파일 작성

  5. /home/jetson/jet_env 파일을 작성하여, checkval=hello 등 필요한 환경 변수를 설정

  6. 서비스 유닛 파일 작성

  7. 사용자 서비스 방식: ~/.config/systemd/user/jetapp.service 파일을 작성하고 동일하게 설정

  8. 서비스 활성화 및 부팅 시 자동 실행 설정

  9. 사용자 서비스의 경우: 
    systemctl --user daemon-reload
systemctl --user enable jetapp.service
systemctl --user start jetapp.service
sudo loginctl enable-linger jetson

이와 같이 설정하면, jetson 사용자가 부팅 시 자동으로 "/home/jetson/jetapp.sh" 스크립트가 실행되어 /home/jetson/jetapp.log 파일에 로그를 남기며, /home/jetson/jet_env 파일을 통해 설정한 환경 변수도 반영됩니다.
