Bash 조건문에서 사용되는 조건 연산자

Bash 조건문에서 사용되는 **조건 연산자**는 크게 다음과 같이 분류할 수 있습니다.

  1. 숫자 비교 연산자
  2. 문자열 비교 연산자
  3. 파일 테스트 연산자
  4. 논리 연산자
  5. 괄호 연산자 ([[ ]], (( )))

1. 숫자 비교 연산자

숫자를 비교할 때는 -eq, -ne, -gt, -lt, -ge, -le 연산자를 사용합니다.
이 연산자는 정수 비교만 가능하며, 실수 비교는 지원되지 않습니다.

연산자 의미 예제
-eq 두 값이 같으면 참 [ "$a" -eq "$b" ]
-ne 두 값이 다르면 참 [ "$a" -ne "$b" ]
-gt 왼쪽 값이 오른쪽 값보다 크면 참 [ "$a" -gt "$b" ]
-lt 왼쪽 값이 오른쪽 값보다 작으면 참 [ "$a" -lt "$b" ]
-ge 왼쪽 값이 오른쪽 값보다 크거나 같으면 참 [ "$a" -ge "$b" ]
-le 왼쪽 값이 오른쪽 값보다 작거나 같으면 참 [ "$a" -le "$b" ]

사용 예제 

a=10
b=20

if [ "$a" -lt "$b" ]; then
    echo "$a 가 $b 보다 작습니다."
fi

2. 문자열 비교 연산자

문자열을 비교할 때는 =, !=, <, >, -z, -n 연산자를 사용합니다.

연산자 의미 예제
= 두 문자열이 같으면 참 [ "$str1" = "$str2" ]
!= 두 문자열이 다르면 참 [ "$str1" != "$str2" ]
< 왼쪽 문자열이 사전순으로 앞이면 참 [ "$str1" \< "$str2" ]
> 왼쪽 문자열이 사전순으로 뒤이면 참 [ "$str1" \> "$str2" ]
-z 문자열이 비어 있으면 참 [ -z "$str" ]
-n 문자열이 비어 있지 않으면 참 [ -n "$str" ]

사용 예제 

str1="hello"
str2="world"

if [ "$str1" != "$str2" ]; then
    echo "두 문자열이 다릅니다."
fi

> 또는 <를 사용할 때는 역슬래시(\)를 앞에 붙여야 합니다.

[[ ]]을 사용하면 역슬래시 없이 비교할 수 있습니다. 

if [[ "apple" > "banana" ]]; then
    echo "apple이 banana보다 사전순으로 뒤에 있습니다."
fi

3. 파일 테스트 연산자

파일이 존재하는지, 읽기/쓰기 가능한지 등을 확인할 때 사용됩니다.

연산자 의미 예제
-e 파일 또는 디렉토리가 존재하는지 확인 [ -e file.txt ]
-f 파일이 존재하는지 확인 (일반 파일인지 확인) [ -f file.txt ]
-d 디렉토리인지 확인 [ -d mydir ]
-s 파일 크기가 0보다 큰지 확인 [ -s file.txt ]
-r 읽기 가능 여부 [ -r file.txt ]
-w 쓰기 가능 여부 [ -w file.txt ]
-x 실행 가능 여부 [ -x script.sh ]

사용 예제 

if [ -f "/etc/passwd" ]; then
    echo "파일이 존재합니다."
else
    echo "파일이 없습니다."
fi

-e는 파일 또는 디렉토리 여부를 구분하지 않으며, 존재 여부만 확인합니다.
-f는 일반 파일인지 확인하는 조건, -d는 디렉토리인지 확인하는 조건입니다.

4. 논리 연산자

조건을 여러 개 조합할 때 사용됩니다.

연산자 의미 예제
&& AND (모든 조건이 참이어야 실행) [ 조건1 ] && [ 조건2 ]
|| OR (하나라도 참이면 실행) [ 조건1 ] || [ 조건2 ]
! NOT (반대 값 반환) [ ! 조건 ]

사용 예제 

if [ "$num" -gt 10 ] && [ "$num" -lt 100 ]; then
    echo "10보다 크고 100보다 작습니다."
fi

[[ ]]을 사용하면 &&와 ||를 직접 사용할 수 있습니다.

if [[ "$num" -gt 10 && "$num" -lt 100 ]]; then
    echo "10보다 크고 100보다 작습니다."
fi

5. 괄호 연산자 ([[ ]], (( )))

[[ ]]과 (( ))을 사용하면 조건문이 더 간결하고 직관적으로 작성할 수 있습니다.

5.1 [[ ]]을 사용한 비교

[[ ]]을 사용하면 -eq 대신 == 사용이 가능하며, <, >를 비교할 때 역슬래시(\)를 사용할 필요가 없습니다.

사용 예제 

if [[ "$str1" == "$str2" ]]; then
    echo "문자열이 같습니다."
fi

문자열 비교 시 [[ ]] 사용을 권장합니다.

5.2 (( ))을 사용한 정수 연산

(( )) 내부에서는 -eq 대신 ==을 사용할 수 있으며, 산술 연산을 직접 수행할 수 있습니다.

사용 예제 

num=20
if (( num > 10 )); then
    echo "숫자가 10보다 큽니다."
fi

(( )) 내부에서는 $ 없이 변수 사용이 가능하며, 산술 연산을 쉽게 수행할 수 있습니다.

6. 정리

분류 연산자 설명
숫자 비교 -eq, -ne, -gt, -lt, -ge, -le 정수 비교 (크기, 같음, 다름)
문자열 비교 =, !=, <, >, -z, -n 문자열 비교 및 빈 값 검사
파일 검사 -e, -f, -d, -s, -r, -w, -x 파일 및 디렉토리 상태 확인
논리 연산자 &&, ||, ! 여러 조건을 조합
확장 조건 [[ ]], (( )) 고급 비교 연산 지원

숫자 비교에는 -eq, -ne, -gt 등을 사용하고,
문자열 비교는 [[ "$str1" == "$str2" ]]을 사용하는 것이 좋습니다.
파일 존재 여부는 [ -f filename ]으로 확인하며,
논리 연산을 조합할 때는 &&와 ||를 활용할 수 있습니다.
