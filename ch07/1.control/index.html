제어문

1. 개요

쉘 스크립트에서 제어문(Control Statements) 은 프로그램의 흐름을 제어하는 중요한 기능입니다.
제어문을 사용하면 조건 판단, 반복 실행, 논리적 흐름 조정 등을 수행할 수 있습니다.

제어문은 크게 **조건문, 반복문, 논리 연산자, 분기문**으로 구분됩니다.

2. 조건문 (Conditional Statements)

조건문은 특정 조건이 참인지 거짓인지에 따라 코드 실행 여부를 결정하는 구조입니다.
쉘에서는 if, elif, case 등을 사용하여 조건을 판단합니다.

2.1 if 문

if 문은 특정 조건이 참일 때만 명령을 실행하는 제어문입니다.

문법

if [ 조건 ]; then
    실행할 명령어
fi

사용 예제

num=10
if [ "$num" -gt 5 ]; then
    echo "숫자가 5보다 큽니다."
fi

2.2 if-else 문

if-else 문은 조건이 참이면 특정 명령을 실행하고, 거짓이면 다른 명령을 실행합니다.

문법

if [ 조건 ]; then
    실행할 명령어1
else
    실행할 명령어2
fi

사용 예제

num=3
if [ "$num" -gt 5 ]; then
    echo "5보다 큽니다."
else
    echo "5보다 작거나 같습니다."
fi

2.3 if-elif-else 문

여러 개의 조건을 차례대로 검사할 때 사용합니다.

문법

if [ 조건1 ]; then
    실행할 명령어1
elif [ 조건2 ]; then
    실행할 명령어2
else
    실행할 명령어3
fi

사용 예제

num=20
if [ "$num" -lt 10 ]; then
    echo "10 미만입니다."
elif [ "$num" -lt 30 ]; then
    echo "10 이상 30 미만입니다."
else
    echo "30 이상입니다."
fi

2.4 case 문

case 문은 여러 개의 조건을 쉽게 표현할 수 있는 방법입니다.

문법

case "$변수" in
    값1) 실행할 명령어 ;;
    값2) 실행할 명령어 ;;
    *) 기본 실행 명령어 ;;
esac

사용 예제

read -p "과일을 입력하세요: " fruit
case "$fruit" in
    apple) echo "사과를 선택했습니다." ;;
    banana) echo "바나나를 선택했습니다." ;;
    *) echo "알 수 없는 과일입니다." ;;
esac

3. 반복문 (Loop Statements)

반복문은 특정 조건이 충족될 때까지 명령을 반복 실행하는 구조입니다.
쉘에서는 for, while, until 문이 제공됩니다.

3.1 for 문

for 문은 리스트의 각 항목에 대해 반복 실행합니다.

문법

for 변수 in 값1 값2 값3; do
    실행할 명령어
done

사용 예제

for file in file1.txt file2.txt file3.txt; do
    echo "$file 을 처리 중..."
done

3.2 while 문

while 문은 조건이 참일 동안 반복 실행합니다.

문법

while [ 조건 ]; do
    실행할 명령어
done

사용 예제

count=5
while [ "$count" -gt 0 ]; do
    echo "카운트다운: $count"
    count=$((count - 1))
    sleep 1
done

3.3 until 문

until 문은 조건이 거짓일 동안 반복 실행합니다.

문법

until [ 조건 ]; do
    실행할 명령어
done

사용 예제

until [ -f "/tmp/ready.txt" ]; do
    echo "파일을 기다리는 중..."
    sleep 1
done
echo "파일이 생성되었습니다!"

4. 분기문 (Break & Continue)

반복문 실행 중 특정 조건이 충족될 경우 반복을 중단하거나 건너뛸 수 있습니다.

4.1 break 문 (반복문 종료)

break 문은 반복문을 즉시 종료합니다.

사용 예제

for i in {1..10}; do
    if [ "$i" -eq 5 ]; then
        echo "5에서 중단!"
        break
    fi
    echo "$i"
done

4.2 continue 문 (현재 반복 건너뛰기)

continue 문은 현재 반복을 건너뛰고 다음 반복으로 이동합니다.

사용 예제

for i in {1..5}; do
    if [ "$i" -eq 3 ]; then
        continue
    fi
    echo "$i"
done

5. 정리

분류 문법
조건문 if, elif, else, case
반복문 for, while, until
분기문 break, continue

쉘 스크립트에서 제어문을 활용하면 자동화된 스크립트 작성을 더욱 효과적으로 할 수 있습니다! 🚀
