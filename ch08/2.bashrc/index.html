Jetson의 .bashrc 파일 해석 및 설명

이 .bashrc 파일은 Jetson Ubuntu 환경에서 Bash 셸이 실행될 때 자동으로 로드되는 설정 파일 입니다.

  • 환경 변수 설정
  • 프롬프트(PS1) 설정
  • Alias(단축 명령어) 설정
  • 컬러 출력 활성화
  • 자동 완성 기능 로드
jetson@ubuntu:~$ cat ~/.bashrc
# ~/.bashrc: executed by bash(1) for non-login shells.
# see /usr/share/doc/bash/examples/startup-files (in the package bash-doc)
# for examples

# If not running interactively, don't do anything
case $- in
    *i*) ;;
      *) return;;
esac

# don't put duplicate lines or lines starting with space in the history.
# See bash(1) for more options
HISTCONTROL=ignoreboth

# append to the history file, don't overwrite it
shopt -s histappend

# for setting history length see HISTSIZE and HISTFILESIZE in bash(1)
HISTSIZE=1000
HISTFILESIZE=2000

# check the window size after each command and, if necessary,
# update the values of LINES and COLUMNS.
shopt -s checkwinsize

# If set, the pattern "**" used in a pathname expansion context will
# match all files and zero or more directories and subdirectories.
#shopt -s globstar

# make less more friendly for non-text input files, see lesspipe(1)
[ -x /usr/bin/lesspipe ] && eval "$(SHELL=/bin/sh lesspipe)"

# set variable identifying the chroot you work in (used in the prompt below)
if [ -z "${debian_chroot:-}" ] && [ -r /etc/debian_chroot ]; then
    debian_chroot=$(cat /etc/debian_chroot)
fi

# set a fancy prompt (non-color, unless we know we "want" color)
case "$TERM" in
    xterm-color|*-256color) color_prompt=yes;;
esac

# uncomment for a colored prompt, if the terminal has the capability; turned
# off by default to not distract the user: the focus in a terminal window
# should be on the output of commands, not on the prompt
#force_color_prompt=yes

if [ -n "$force_color_prompt" ]; then
    if [ -x /usr/bin/tput ] && tput setaf 1 >&/dev/null; then
        # We have color support; assume it's compliant with Ecma-48
        # (ISO/IEC-6429). (Lack of such support is extremely rare, and such
        # a case would tend to support setf rather than setaf.)
        color_prompt=yes
    else
        color_prompt=
    fi
fi

if [ "$color_prompt" = yes ]; then
    PS1='${debian_chroot:+($debian_chroot)}\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ '
else
    PS1='${debian_chroot:+($debian_chroot)}\u@\h:\w\$ '
fi
unset color_prompt force_color_prompt

# If this is an xterm set the title to user@host:dir
case "$TERM" in
xterm*|rxvt*)
    PS1="\[\e]0;${debian_chroot:+($debian_chroot)}\u@\h: \w\a\]$PS1"
    ;;
*)
    ;;
esac

# enable color support of ls and also add handy aliases
if [ -x /usr/bin/dircolors ]; then
    test -r ~/.dircolors && eval "$(dircolors -b ~/.dircolors)" || eval "$(dircolors -b)"
    alias ls='ls --color=auto'
    #alias dir='dir --color=auto'
    #alias vdir='vdir --color=auto'

    alias grep='grep --color=auto'
    alias fgrep='fgrep --color=auto'
    alias egrep='egrep --color=auto'
fi

# colored GCC warnings and errors
#export GCC_COLORS='error=01;31:warning=01;35:note=01;36:caret=01;32:locus=01:quote=01'

# some more ls aliases
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'

# Add an "alert" alias for long running commands.  Use like so:
#   sleep 10; alert
alias alert='notify-send --urgency=low -i "$([ $? = 0 ] && echo terminal || echo error)" "$(history|tail -n1|sed -e '\''s/^\s*[0-9]\+\s*//;s/[;&|]\s*alert$//'\'')"'

# Alias definitions.
# You may want to put all your additions into a separate file like
# ~/.bash_aliases, instead of adding them here directly.
# See /usr/share/doc/bash-doc/examples in the bash-doc package.

if [ -f ~/.bash_aliases ]; then
    . ~/.bash_aliases
fi

# enable programmable completion features (you don't need to enable
# this, if it's already enabled in /etc/bash.bashrc and /etc/profile
# sources /etc/bash.bashrc).
if ! shopt -oq posix; then
  if [ -f /usr/share/bash-completion/bash_completion ]; then
    . /usr/share/bash-completion/bash_completion
  elif [ -f /etc/bash_completion ]; then
    . /etc/bash_completion
  fi
fi

alias msg='sudo dmesg | tail -n 10'

jetson@ubuntu:~$

1. 실행 조건 확인

# ~/.bashrc: executed by bash(1) for non-login shells.
✅ .bashrc는 **비로그인 셸**에서 실행됨.
✅ **로그인 셸 (예: SSH 로그인)**에서는 .bash_profile이 실행됨.

📌 로그인 셸 vs 비로그인 셸
| 셸 유형 | 실행되는 파일 | |---------|-------------| | 로그인 셸 (ssh user@host) | .bash_profile → .bashrc 호출 가능 | | 비로그인 셸 (bash 실행) | .bashrc 직접 실행 |

2. 인터랙티브 셸인지 확인

# If not running interactively, don't do anything
case $- in
    *i*) ;;  # 인터랙티브 셸이면 계속 실행
      *) return;;  # 비인터랙티브 셸이면 종료
esac
✅ 인터랙티브 셸인지 확인하여, 그렇지 않으면 실행 중단
✅ case $- in *i*) → $- 변수에 i가 포함되어 있으면 사용자가 직접 조작할 수 있는 셸
✅ return → 비인터랙티브 셸이면 .bashrc 실행 종료

📌 인터랙티브 셸이 아닌 경우 예시

bash script.sh  # 비인터랙티브 실행 → .bashrc 실행되지 않음

3. 히스토리 관련 설정

HISTCONTROL=ignoreboth
shopt -s histappend
HISTSIZE=1000
HISTFILESIZE=2000
✅ history 명령어와 관련된 설정
| 설정 | 설명 | |------|------| | HISTCONTROL=ignoreboth | 중복된 명령어 및 공백으로 시작하는 명령어를 히스토리에서 제외 | | shopt -s histappend | 새로운 명령어를 기존 히스토리에 추가 (덮어쓰지 않음) | | HISTSIZE=1000 | 메모리에 저장할 최대 히스토리 개수 | | HISTFILESIZE=2000 | ~/.bash_history 파일에 저장할 최대 히스토리 개수 |

4. 터미널 크기 자동 업데이트

shopt -s checkwinsize
✅ 윈도우 크기가 변경될 때 LINES 및 COLUMNS 값을 자동 업데이트
✅ 터미널 크기 조정 시 ls 등의 출력이 깨지지 않도록 함

5. less 명령어 최적화

[ -x /usr/bin/lesspipe ] && eval "$(SHELL=/bin/sh lesspipe)"
✅ 텍스트 뷰어(less)를 더 다양한 파일 형식에서 사용할 수 있도록 설정
✅ lesspipe는 압축된 파일도 자동으로 해석 가능

6. chroot 환경인지 확인

if [ -z "${debian_chroot:-}" ] && [ -r /etc/debian_chroot ]; then
    debian_chroot=$(cat /etc/debian_chroot)
fi
✅ 현재 환경이 chroot 상태인지 확인
✅ chroot는 리눅스에서 격리된 환경을 제공하는 기능

7. 프롬프트 (PS1) 설정

case "$TERM" in
    xterm-color|*-256color) color_prompt=yes;;
esac
✅ 터미널이 색상을 지원하면 color_prompt 활성화
✅ xterm-color 또는 *-256color 환경에서 색상 지원 

if [ "$color_prompt" = yes ]; then
    PS1='${debian_chroot:+($debian_chroot)}\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ '
else
    PS1='${debian_chroot:+($debian_chroot)}\u@\h:\w\$ '
fi
✅ 프롬프트(PS1) 설정 | 코드 | 설명 | |------|------| | \u | 현재 사용자 이름 | | \h | 호스트명 (컴퓨터 이름) | | \w | 현재 작업 디렉토리 | | \[\033[01;32m\] | 초록색 (32m)으로 사용자명 표시 | | \[\033[01;34m\] | 파란색 (34m)으로 디렉토리 표시 |

📌 출력 예시 

jetson@ubuntu:~$

8. ls, grep 등 컬러 출력 활성화

if [ -x /usr/bin/dircolors ]; then
    test -r ~/.dircolors && eval "$(dircolors -b ~/.dircolors)" || eval "$(dircolors -b)"
    alias ls='ls --color=auto'
    alias grep='grep --color=auto'
    alias fgrep='fgrep --color=auto'
    alias egrep='egrep --color=auto'
fi
✅ ls, grep 등의 명령어에 컬러 출력 적용
✅ ls --color=auto → 파일 및 디렉토리 색상 표시

📌 적용 후 ls 실행 시 색상 출력 예시 

ls
# 파일(흰색), 디렉토리(파란색), 실행 파일(녹색) 등 컬러 구분

9. 추가적인 ls 단축 명령어 설정

alias ll='ls -alF'
alias la='ls -A'

✅ ll, la, l 명령어를 ls로 빠르게 실행할 수 있도록 설정

📌 사용 예시 

ll   # 'ls -alF' 실행 → 자세한 파일 목록 출력

10. 긴 실행 명령어 완료 후 알림 (alert alias)

alias alert='notify-send --urgency=low -i "$([ $? = 0 ] && echo terminal || echo error)" "$(history|tail -n1|sed -e '\''s/^\s*[0-9]\+\s*//;s/[;&|]\s*alert$//'\'')"'
✅ 긴 실행이 끝났을 때 알림을 표시하는 alias (notify-send 사용)
✅ GUI 환경에서 실행 가능 (터미널이 종료되지 않아야 함)

11. 사용자 정의 alias 추가 (~/.bash_aliases 불러오기)

if [ -f ~/.bash_aliases ]; then

✅ ~/.bash_aliases 파일이 존재하면 자동 실행
✅ 사용자 정의 alias를 따로 관리 가능

✅ .bashrc는 로그인 후 셸 환경을 자동으로 설정하는 중요한 파일 🚀

$- 변수란?

$- (hyphen, dash) 변수는 현재 셸의 실행 옵션(flag)을 나타내는 특수 변수**입니다.
- bash 셸이 어떤 모드에서 실행되고 있는지 확인하는 데 사용됨
- 주요 옵션: **인터랙티브 모드(i), 배치 모드(h), 디버깅 모드(x) 등

$- 변수 값 확인

echo "$-"

출력 예시 (인터랙티브 셸에서 실행)

himBH
각 문자의 의미는 다음과 같습니다: | 옵션 | 설명 | |------|------| | h | 해시(Hash) 테이블 사용 | | i | 인터랙티브 셸 (Interactive Mode) | | m | 잡 제어(Job Control) 사용 가능 | | B | Brace Expansion(중괄호 확장) 활성화 | | H | 명령어 히스토리 활성화 |

✅ 대부분의 경우 i가 포함되면 인터랙티브 셸(사용자 입력을 받는 셸), 없으면 스크립트 실행 모드(비인터랙티브)임.

.bashrc에서 $- 사용 (case $- in)

# If not running interactively, don't do anything
case $- in
    *i*) ;;   # 인터랙티브 셸이면 계속 실행
      *) return;;  # 그렇지 않으면 실행 종료
esac

설명

1️⃣ $- 변수를 확인하여 실행 모드 결정
2️⃣ *i*) ;; → i가 포함되어 있으면 (인터랙티브 모드) .bashrc 계속 실행
3️⃣ *) return;; → 인터랙티브 모드가 아니면 .bashrc 실행 중단

📌 즉, 인터랙티브가 아닌 환경(스크립트 실행, scp 실행 등)에서는 .bashrc의 나머지 내용을 실행하지 않도록 함.

$- 값이 다르게 나오는 경우

📌 인터랙티브 셸에서 확인 

echo "$-"

himBH
✅ i가 포함 → 인터랙티브 셸

📌 스크립트 실행 모드에서 확인 

bash -c 'echo "$-"'

hB
✅ i가 없음 → 비인터랙티브 모드

$- 정리

값 의미
$- 현재 셸 옵션 표시 (himBH 등)
i 포함 인터랙티브 모드 (사용자가 직접 입력 가능)
i 없음 비인터랙티브 모드 (스크립트 실행 모드)

✅ .bashrc에서 $-을 사용하여 비인터랙티브 환경에서는 불필요한 설정을 실행하지 않도록 제어 가능 🚀
