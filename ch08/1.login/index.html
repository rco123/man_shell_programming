**로그인 후 환경 적용 **

리눅스에서 사용자가 로그인하면 **셸 환경 설정이 자동으로 적용**됩니다.
이 과정에서 **사용자 정보 로드 → 셸 실행 → 환경 변수 설정**이 수행됩니다.

1. 로그인 과정 개요

1️⃣ 사용자 인증 → 로그인 요청을 받고 계정 정보 확인 (/etc/passwd, /etc/shadow)
2️⃣ 사용자 셸 실행 → 로그인 셸 (bash, zsh, sh 등) 실행
3️⃣ 환경 설정 파일 실행 → .bashrc, .bash_profile, /etc/profile 등 로드
4️⃣ 환경 변수 및 PATH 설정 → 시스템 환경 및 사용자별 설정 적용
5️⃣ 프롬프트 표시 → 사용자가 명령어를 입력할 수 있도록 셸 시작

2. 로그인 과정 상세 설명

1) 사용자 인증 (PAM을 통한 로그인)

  • 로그인 요청이 들어오면 **PAM (Pluggable Authentication Modules)**이 사용자 인증을 수행
  • 사용자 정보는 /etc/passwd, /etc/shadow, /etc/group 파일에서 확인됨

인증 과정

1. 로그인 입력 → 사용자가 아이디/비밀번호 입력
2. PAM 모듈 확인 → /etc/pam.d/ 경로에서 로그인 방식 확인
3. 사용자 계정 확인 → /etc/passwd에서 계정 정보 조회
4. 비밀번호 검증 → /etc/shadow에서 암호화된 비밀번호 확인
5. 인증 성공 → 사용자 셸 실행
📌 관련 파일 - /etc/passwd → 사용자 계정 정보 저장 (username:x:uid:gid:home:shell) - /etc/shadow → 암호화된 비밀번호 저장 - /etc/group → 사용자 그룹 정보 저장

2) 로그인 셸 실행

  • 사용자가 로그인하면 기본적으로 설정된 **로그인 셸**이 실행됨
  • 기본 로그인 셸은 /etc/passwd 파일에서 확인 가능
    cat /etc/passwd | grep username

출력 예시

username:x:1000:1000:User Name:/home/username:/bin/bash
🔹 /bin/bash → 해당 사용자의 기본 셸

3) 환경 설정 파일 로드

로그인 시 **사용자의 환경을 구성하는 설정 파일이 자동 실행**됨.
**로그인 셸인지 여부**에 따라 실행되는 파일이 다름.

(A) 로그인 셸 실행 순서

  1. /etc/profile → 시스템 전역 환경 변수 로드
  2. ~/.bash_profile 또는 ~/.profile → 사용자별 환경 변수 설정
  3. ~/.bashrc → 별도로 실행되며, bash_profile에서 호출될 수도 있음

(B) 비로그인 셸 실행 순서

  1. /etc/bash.bashrc → 시스템 전역 설정
  2. ~/.bashrc → 사용자별 환경 변수 설정
  3. ~/.bash_aliases (존재하는 경우) → 사용자별 alias 설정

📌 로그인 셸 vs 비로그인 셸 | 셸 유형 | 실행되는 파일 | 설명 | |---------|--------------|------| | 로그인 셸 | /etc/profile, ~/.bash_profile, ~/.profile | 원격 로그인(ssh) 또는 TTY 로그인 시 실행 | | 비로그인 셸 | /etc/bash.bashrc, ~/.bashrc | 터미널에서 bash 실행 시 적용 |

✅ 그래픽 환경(GUI)에서 터미널 실행 시 → 비로그인 셸
✅ SSH 접속 시 → 로그인 셸

4) 환경 변수 및 PATH 설정

환경 설정 파일에서 **다양한 환경 변수**를 정의하고 실행할 수 있음.

(A) 기본 환경 변수

export PATH="/usr/local/bin:/usr/bin:/bin"
export LANG="en_US.UTF-8"
export EDITOR="vim"
- PATH → 실행 가능한 명령어 검색 경로 - LANG → 시스템 언어 설정 - EDITOR → 기본 텍스트 편집기 설정

(B) .bashrc에서 실행되는 설정 예제

# 사용자 정의 환경 변수
export MY_VAR="Hello World"

# alias 설정
alias ll='ls -alF'
alias gs='git status'

# 프롬프트 설정
export PS1="\u@\h:\w$ "

5) 프롬프트 표시 및 사용자 환경 적용 완료

  • 환경 변수 적용 후 프롬프트가 표시됨
  • 사용자가 명령어를 입력할 준비가 완료됨 

username@hostname:~$
이제 사용자가 명령을 입력하면 **셸이 실행하고 결과를 반환**함.

3. 로그인 후 환경 설정 적용 과정 요약

1. 사용자 로그인 → PAM을 통해 인증 확인 (/etc/passwd, /etc/shadow)
2. 로그인 셸 실행 → /bin/bash 또는 /bin/zsh 등 실행
3. 환경 설정 파일 실행 → /etc/profile → ~/.bash_profile → ~/.bashrc
4. 환경 변수 적용 → PATH, LANG, EDITOR 등 설정
5. 프롬프트 표시 → 사용자 입력 대기

4. 로그인 후 환경 설정 변경하기

사용자가 직접 환경 변수를 설정하거나 .bashrc 등을 수정하면 **로그인 후 실행될 환경을 변경**할 수 있음.

1) 환경 변수 일시 적용

export MY_VAR="Temporary Value"
echo $MY_VAR  # Temporary Value
- 현재 셸에서만 유지되며, 로그아웃 시 사라짐

2) 영구적인 환경 변수 설정

  • .bashrc 또는 .bash_profile에 추가
    echo 'export MY_VAR="Persistent Value"' >> ~/.bashrc
  • 적용하려면 **로그아웃 후 다시 로그인**하거나 아래 명령어 실행 
    source ~/.bashrc

✅ 이제 로그인할 때마다 MY_VAR가 자동 적용됨!

5. 정리

단계 과정 설명
1 사용자 인증 /etc/passwd, /etc/shadow 확인 후 로그인 처리
2 로그인 셸 실행 사용자의 기본 셸 (bash, zsh) 실행
3 환경 설정 파일 로드 /etc/profile, ~/.bash_profile, ~/.bashrc 실행
4 환경 변수 설정 PATH, LANG, EDITOR 등의 환경 변수 적용
5 프롬프트 표시 로그인 완료 후 사용자가 명령 입력 가능

✅ 로그인하면 환경 설정 파일이 실행되고, 환경 변수가 적용된 후 프롬프트가 표시됨
✅ 셸 환경을 수정하려면 .bashrc 또는 .bash_profile을 수정하면 됨 🚀
