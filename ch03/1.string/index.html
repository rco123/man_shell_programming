쉘에서 문자열 만드는 방법

1. ""(더블 쿼트)와 ''(싱글 쿼트)의 차이

  • ""(더블 쿼트, Double Quotes)

    • 변수 치환이 가능 하며, $, \, ` 같은 특수 문자를 해석
    • 명령어 치환 $( ) 또는 백틱(`)도 사용 가능 
    name="Bash"
echo "Hello, $name!"  # Hello, Bash!

  • ''(싱글 쿼트, Single Quotes)

    • 변수 치환이 불가능 하며, 입력한 문자열 그대로 사용
    • $, \, ` 등의 특수 문자도 일반 문자로 처리 
    name="Bash"
echo 'Hello, $name!'  # Hello, $name!

비교 요약

구분 ""(더블 쿼트) ''(싱글 쿼트)
변수 사용 ✅ 변수 치환 가능 ❌ 변수 치환 불가능
명령어 치환 ✅ 가능 ($( ) 지원) ❌ 불가능
특수 문자 처리 ✅ 일부 문자 해석 ($, ` 등) ❌ 문자 그대로 출력

2. 문자열을 만드는 다양한 방법

1) 더블 쿼트를 사용한 변수 할당

greeting="Hello, World!"
echo "$greeting"  # Hello, World!

2) 싱글 쿼트를 사용한 변수 할당

greeting='Hello, World!'
echo "$greeting"  # Hello, World!

3) 그냥 문자열을 변수에 대입 (따옴표 없이)

greeting=Hello
echo "$greeting"  # Hello
- 공백이 없는 경우 에는 따옴표 없이 변수에 값을 할당할 수 있음
- 공백이 포함된 문자열은 반드시 "" 또는 ''로 감싸야 함 

greeting=Hello, World!  # 오류 발생
greeting="Hello, World!"  # 정상 동작

비교 요약

방법 사용 예제 특징
""(더블 쿼트) greeting="Hello, $name" 변수 치환 가능
''(싱글 쿼트) greeting='Hello, $name' 변수 치환 불가능
그냥 대입 greeting=Hello 공백이 없는 경우만 사용 가능

3. {}를 사용하여 문자열을 생성하는 방법

1) ${변수}를 사용하여 문자열을 안전하게 결합

name="Shell"
echo "Welcome to ${name}Scripting!"  # Welcome to ShellScripting!
echo "Welcome to $nameScripting!"    # 오류 발생
- ${변수}를 사용하면 변수명과 문자열을 명확히 구분할 수 있음 - $nameScripting으로 작성하면 nameScripting이라는 변수를 찾게 되어 오류 발생

2) {}를 활용한 문자열 조합

greeting="Hello"
target="World"

# 문자열 결합
message="${greeting}, ${target}!"
echo "$message"  # Hello, World!

3) {}를 사용한 기본값 설정

  • 변수가 비어 있을 경우 기본값을 설정하는 방법 

name=""
echo "Hello, ${name:-Guest}!"  # Hello, Guest!

name="Alice"
echo "Hello, ${name:-Guest}!"  # Hello, Alice!
- ${변수:-기본값}: 변수가 비어 있으면 기본값 사용

4) {}를 사용한 문자열 길이 계산

text="Hello"
echo "문자열 길이: ${#text}"  # 5

비교 요약

방법 사용 예제 기능
${변수} "Hello, ${name}!" 문자열 결합 시 변수명을 명확하게 구분
${변수:-기본값} "Hello, ${name:-Guest}!" 변수가 비어 있을 경우 기본값 사용
${#변수} "${#text}" 문자열 길이 계산

정리

  • ""(더블 쿼트)와 ''(싱글 쿼트)의 차이: ""는 변수 치환 가능, ''는 문자열 그대로 유지
  • 문자열을 만들 때 "", '', 그냥 대입의 차이 : 공백이 있는 경우 "" 또는 '' 필요
  • {}를 활용하여 문자열을 조합하고 변수를 안전하게 사용 가능
  • ${변수:-기본값}으로 기본값을 설정하고 ${#변수}로 문자열 길이 계산 가능

쉘에서 문자열을 다루는 방법을 익히면 보다 유연한 스크립트를 작성할 수 있음.
