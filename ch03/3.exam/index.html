문자열을 생성하는 실습 예제

1. 변수에 문자열 저장 및 출력

설명

  • 변수에 문자열을 저장하고 echo로 출력하는 기본 예제

코드 예제

#!/bin/bash

# 변수 선언
greeting="Hello, Bash!"
name="Alice"

# 문자열 출력
echo "$greeting"
echo "Welcome, $name!"

실행 결과

Hello, Bash!
Welcome, Alice!

2. 더블 쿼트("")와 싱글 쿼트('') 차이점 실습

설명

  • ""(더블 쿼트)와 ''(싱글 쿼트)의 차이를 확인하는 예제

코드 예제

#!/bin/bash

# 변수 선언
name="Bash"

# 더블 쿼트 사용
echo "Hello, $name!"  # 변수 치환 가능

# 싱글 쿼트 사용
echo 'Hello, $name!'  # 변수 치환 불가능 (문자 그대로 출력)

실행 결과

Hello, Bash!
Hello, $name!

3. 문자열 길이 계산

설명

  • ${#변수}를 사용하여 문자열의 길이를 계산하는 실습

코드 예제

#!/bin/bash

# 문자열 선언
text="Shell Scripting"

# 문자열 길이 출력
echo "문자열: $text"
echo "문자열 길이: ${#text}"

실행 결과

문자열: Shell Scripting
문자열 길이: 15

4. 부분 문자열 추출

설명

  • ${변수:시작위치:길이}를 사용하여 문자열에서 특정 부분을 추출

코드 예제

#!/bin/bash

# 문자열 선언
text="Shell Scripting"

# 부분 문자열 추출
echo "원본 문자열: $text"
echo "부분 문자열 (0~4): ${text:0:5}"
echo "부분 문자열 (6~끝까지): ${text:6}"

실행 결과

원본 문자열: Shell Scripting
부분 문자열 (0~4): Shell
부분 문자열 (6~끝까지): Scripting

5. 문자열 치환

설명

  • ${변수/찾을값/바꿀값}을 사용하여 문자열 일부를 치환하는 실습

코드 예제

#!/bin/bash

# 문자열 선언
text="I love Bash scripting"

# 문자열 치환
new_text=${text/Bash/Python}

# 출력
echo "원본 문자열: $text"
echo "치환된 문자열: $new_text"

실행 결과

원본 문자열: I love Bash scripting
치환된 문자열: I love Python scripting

6. 문자열 연결 (Concatenation)

설명

  • 여러 개의 문자열을 하나로 합치는 실습

코드 예제

#!/bin/bash

# 변수 선언
str1="Hello"
str2="World"

# 문자열 연결
greeting="$str1, $str2!"

# 출력
echo "$greeting"

실행 결과

Hello, World!

7. 사용자 입력을 문자열로 저장

설명

  • read 명령어를 사용하여 사용자의 입력을 문자열 변수로 저장

코드 예제

#!/bin/bash

# 사용자 입력 받기
echo "이름을 입력하세요:"
read user_name

# 입력값 출력
echo "환영합니다, $user_name!"

실행 예시

이름을 입력하세요:
Alice
환영합니다, Alice!

8. 명령어 치환을 이용한 문자열 생성

설명

  • $(명령어)를 사용하여 명령어 실행 결과를 문자열로 저장

코드 예제

#!/bin/bash

# 현재 날짜를 문자열로 저장
current_date=$(date "+%Y-%m-%d")
current_time=$(date "+%H:%M:%S")

# 출력
echo "오늘 날짜: $current_date"
echo "현재 시간: $current_time"

실행 결과

오늘 날짜: 2025-02-26
현재 시간: 14:30:45

9. 환경 변수를 이용한 문자열 생성

설명

  • export를 사용하여 환경 변수를 설정하고 문자열로 활용하는 실습

코드 예제

#!/bin/bash

# 환경 변수 설정
export GREETING="Hello, Linux User!"

# 다른 스크립트에서 환경 변수 사용 가능
echo "$GREETING"

실행 결과

Hello, Linux User!

10. 와일드카드 *을 이용한 문자열 처리

설명

  • *(와일드카드)를 사용하여 특정 패턴의 파일 목록을 문자열로 저장하는 실습

코드 예제

#!/bin/bash

# 현재 디렉토리의 .sh 파일 목록을 문자열로 저장
files=$(ls *.sh)

# 출력
echo "스크립트 파일 목록: $files"

실행 결과 (현재 디렉토리에 script1.sh, script2.sh가 있을 경우)

스크립트 파일 목록: script1.sh script2.sh

정리

  • 변수를 활용한 문자열 생성 및 출력
  • 문자열 길이 계산, 부분 문자열 추출, 문자열 치환
  • 여러 문자열 연결, 사용자 입력을 문자열로 저장
  • 명령어 치환을 이용하여 동적인 문자열 생성
  • 환경 변수 및 와일드카드를 활용한 문자열 처리

쉘 스크립트에서 문자열을 다루는 다양한 방법을 익히면 더욱 강력한 자동화 스크립트를 작성할 수 있음. 🚀
