쉘에서 문자열을 구성하는 특수 문자들

쉘에서 문자열을 다룰 때 다양한 **특수 문자**가 사용되며, 각각의 의미와 용도가 다름.
특수 문자를 올바르게 사용하면 보다 강력하고 유연한 스크립트를 작성할 수 있음.

1. 기본 특수 문자

특수 문자 의미 예제
* 와일드카드 (모든 문자열과 매칭) ls *.txt → 모든 .txt 파일 표시
? 단일 문자와 매칭 ls file?.txt → file1.txt, fileA.txt 등과 매칭
~ 사용자의 홈 디렉토리 cd ~ → /home/user로 이동
$ 변수 값 참조 echo $HOME → /home/user 출력
{} 문자열 그룹 또는 변수 확장 echo {one,two,three} → one two three 출력
[] 문자 클래스 지정 ls file[1-3].txt → file1.txt, file2.txt, file3.txt 검색
\ 특수 문자 이스케이프 echo \$HOME → $HOME 출력
' ' 싱글 쿼트(문자 그대로 해석) 'echo $HOME' → echo $HOME 출력
" " 더블 쿼트(변수 치환 가능) "echo $HOME" → /home/user 출력
` ` 명령어 치환(백틱) echo `date` → 현재 날짜 출력
$( ) 명령어 치환 echo $(date) → 현재 날짜 출력

2. 문자열 확장에 관련된 특수 문자

특수 문자 의미 예제
${변수} 변수 값 출력 echo ${USER} → user 출력
${변수:-기본값} 변수가 비어 있으면 기본값 사용 echo ${name:-Guest}
${#변수} 문자열 길이 계산 text="hello"; echo ${#text} → 5 출력
${변수:시작:길이} 부분 문자열 추출 echo ${text:1:3} → ell 출력
${변수/패턴/치환값} 첫 번째 패턴 치환 text="hello"; echo ${text/l/x} → hexlo
${변수//패턴/치환값} 모든 패턴 치환 text="hello"; echo ${text//l/x} → hexxo

3. 명령어 및 프로세스 관련 특수 문자

특수 문자 의미 예제
| 파이프(출력 → 입력) ls | grep txt
> 출력 리디렉션(덮어쓰기) echo "Hello" > file.txt
>> 출력 리디렉션(추가) echo "Hello" >> file.txt
< 입력 리디렉션 sort < file.txt
& 백그라운드 실행 sleep 10 &
&& 명령어 연속 실행 (성공 시) mkdir test && cd test
|| 명령어 연속 실행 (실패 시) mkdir test || echo "생성 실패"
; 여러 명령어 한 줄 실행 echo "Hello"; ls

4. 특수 문자 활용 예제

1) *(와일드카드) 사용 예제

ls *.sh  # 확장자가 .sh인 모든 파일 출력

2) ${}를 이용한 문자열 처리

text="Hello Bash"
echo ${text:6}   # Bash 출력
echo ${text:0:5} # Hello 출력
echo ${#text}    # 문자열 길이 출력 (11)

3) 명령어 치환을 이용한 문자열 생성

today=$(date +%Y-%m-%d)
echo "오늘 날짜: $today"

쉘에서 문자열을 다룰 때 위의 특수 문자들을 잘 활용하면 더욱 효율적인 스크립트를 작성할 수 있음. 🚀
