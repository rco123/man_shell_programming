find 명령어 개요

1. find란?

  • 파일 및 디렉토리를 검색하는 명령어
  • 지정한 경로에서 특정 조건(이름, 크기, 수정 시간 등)에 맞는 파일을 찾을 수 있음
  • 검색 결과를 기반으로 **삭제, 복사, 이동 등 다양한 작업을 자동화**할 수 있음

2. 기본 문법

find [검색할 경로] [옵션] [검색 조건] [실행할 작업]
- [검색할 경로] → 검색을 수행할 디렉토리 (/, . 등)
- [옵션] → 검색 조건 설정 (-name, -size, -type 등)
- [검색 조건] → 특정 파일명, 크기, 날짜 등을 지정
- [실행할 작업] → 검색된 파일에 대해 수행할 작업 (-exec, -delete 등)

3. find의 주요 옵션

옵션 설명 예제
-name 특정 파일 이름 검색 find . -name "test.txt"
-iname 대소문자 무시하고 검색 find . -iname "TEST.txt"
-type 파일 유형 지정 (f: 파일, d: 디렉토리) find . -type f -name "*.sh"
-size 파일 크기로 검색 (+: 초과, -: 미만) find . -size +10M (10MB 초과)
-mtime 수정된 지 N일 지난 파일 검색 find . -mtime -7 (7일 이내 수정)
-atime 마지막으로 접근한 지 N일 지난 파일 검색 find . -atime +30 (30일 이상 미접근)
-ctime 파일의 속성이 변경된 지 N일 지난 파일 검색 find . -ctime -3 (3일 이내 변경)
-perm 파일의 권한을 기준으로 검색 find . -perm 644
-user 특정 사용자가 소유한 파일 검색 find . -user root
-group 특정 그룹이 소유한 파일 검색 find . -group staff
-empty 빈 파일 또는 빈 디렉토리 검색 find . -type f -empty

4. find 명령어 실습 예제

1) 특정 파일 검색 (-name)

find /home/user -name "test.txt"
- /home/user 디렉토리에서 "test.txt" 파일을 찾음

2) 특정 확장자를 가진 파일 검색 (-name "*.확장자")

find . -name "*.sh"
- 현재 디렉토리(.)에서 모든 .sh 파일 검색

3) 특정 크기 이상의 파일 검색 (-size)

find /var/log -size +100M
- /var/log 디렉토리에서 100MB 초과 파일 검색

4) 특정 날짜 이후 수정된 파일 검색 (-mtime)

find /home/user -mtime -7
- /home/user 디렉토리에서 최근 7일 이내 수정된 파일 검색

5) 특정 사용자가 소유한 파일 검색 (-user)

find / -user root
- 루트(/) 디렉토리에서 root 사용자가 소유한 파일 검색

6) 특정 권한을 가진 파일 검색 (-perm)

find /home/user -type f -perm 644
- /home/user 디렉토리에서 644(읽기/쓰기/읽기) 권한을 가진 파일 검색

7) 빈 파일 및 디렉토리 검색 (-empty)

find . -type f -empty
- 현재 디렉토리에서 빈 파일 검색 

find . -type d -empty
- 현재 디렉토리에서 빈 디렉토리 검색

5. find와 exec를 사용하여 검색 결과에 작업 수행

find는 -exec 옵션을 사용하여 검색된 파일에 특정 명령을 실행할 수 있음

1) 검색된 파일 삭제 (-exec rm)

find /tmp -type f -name "*.log" -exec rm {} \;
- /tmp 디렉토리에서 .log 파일을 찾은 후 삭제

2) 검색된 파일을 다른 디렉토리로 이동 (-exec mv)

find . -type f -name "*.txt" -exec mv {} /backup/ \;
- 현재 디렉토리에서 모든 .txt 파일을 /backup/으로 이동

3) 검색된 파일의 상세 정보 출력 (-exec ls -l)

find . -type f -name "*.sh" -exec ls -l {} \;
- 현재 디렉토리에서 모든 .sh 파일을 찾아 상세 정보 출력

6. find와 xargs를 활용한 대량 처리

xargs를 사용하면 find 결과를 효율적으로 명령어에 전달 가능

1) 검색된 파일을 한 번에 삭제 (xargs rm)

find . -type f -name "*.tmp" | xargs rm
- 현재 디렉토리에서 .tmp 파일을 한 번에 삭제

2) 검색된 파일을 압축 (xargs tar)

find /var/log -type f -name "*.log" | xargs tar -czf logs.tar.gz
- /var/log의 모든 .log 파일을 logs.tar.gz로 압축

7. find와 -delete를 사용한 파일 삭제

1) 특정 확장자의 파일 삭제

find . -type f -name "*.bak" -delete
- 현재 디렉토리에서 .bak 파일 삭제

2) 특정 크기 이상의 파일 삭제

find /var/log -type f -size +500M -delete
- /var/log에서 500MB 초과 파일 삭제

정리

  • find는 파일 및 디렉토리를 검색하는 강력한 명령어
  • 이름, 크기, 날짜, 소유자, 권한 등 다양한 조건으로 검색 가능
  • -exec 또는 xargs를 사용하면 검색된 파일에 대해 작업 수행 가능
  • -delete 옵션을 사용하여 특정 파일을 빠르게 삭제 가능

find 명령어를 활용하면 파일 검색, 정리, 자동화 작업을 효율적으로 수행할 수 있음 🚀
