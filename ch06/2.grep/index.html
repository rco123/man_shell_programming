grep 명령어 개요 및 사용법 (옵션 조합 및 디렉토리 검색 추가)

1. grep이란?

  • grep은 파일 또는 표준 입력에서 특정 패턴(문자열, 정규식)을 검색하는 명령어
  • 검색 결과가 포함된 줄만 출력
  • 다른 명령어(ls, ps, find 등)와 함께 사용 가능
  • 텍스트 필터링 및 로그 분석에 유용
  • 옵션을 조합하여 보다 강력한 검색 가능
  • 디렉토리 검색을 통해 하위 폴더 내 파일에서도 문자열 검색 가능

2. grep 기본 문법

grep [옵션1] [옵션2] "검색할_패턴" [파일명 또는 디렉토리]
- "검색할_패턴" → 찾고자 하는 문자열 또는 정규식 - [파일명 또는 디렉토리] → 검색할 대상 (파일/디렉토리/표준 입력) - [옵션] → 검색 방식 변경 (대소문자 무시, 전체 단어 검색 등)

3. grep 기본 사용법

1) 특정 단어 포함된 줄 검색

grep "error" logfile.txt
- logfile.txt에서 "error"가 포함된 줄만 출력

실행 결과

[ERROR] File not found
[ERROR] Connection timeout

2) 여러 파일에서 특정 문자열 검색

grep "TODO" *.txt
- 현재 디렉토리의 모든 .txt 파일에서 "TODO" 포함된 줄 검색

3) 표준 입력에서 grep 사용

cat logfile.txt | grep "error"
- cat logfile.txt의 출력에서 "error"가 포함된 줄만 grep으로 필터링 - 보통 **파이프(|)와 함께 사용**하여 명령어 출력을 필터링할 때 유용

4. grep의 주요 옵션

옵션 설명 예제
-i 대소문자 무시 grep -i "error" logfile.txt
-v 해당 패턴을 포함하지 않는 줄 출력 (반전 검색) grep -v "error" logfile.txt
-c 검색된 줄 개수 출력 grep -c "error" logfile.txt
-n 줄 번호 포함 출력 grep -n "error" logfile.txt
-w 완전한 단어만 검색 grep -w "error" logfile.txt
-r 하위 디렉토리 포함하여 검색 (재귀 검색) grep -r "error" /var/log/
-R 심볼릭 링크가 포함된 디렉토리 검색 grep -R "error" /var/log/
-l 검색된 파일 이름만 출력 grep -l "error" *.log
-o 매칭된 단어만 출력 grep -o "error" logfile.txt
-A N 일치하는 줄 이후 N줄 출력 grep -A 3 "error" logfile.txt
-B N 일치하는 줄 이전 N줄 출력 grep -B 3 "error" logfile.txt
-C N 일치하는 줄 전후 N줄 출력 grep -C 3 "error" logfile.txt
-E 확장 정규식 사용 (egrep과 동일) grep -E "error|fail"

5. grep 옵션을 조합하여 사용하기

1) 대소문자 무시 + 줄 번호 출력

grep -i -n "error" logfile.txt
- "error", "ERROR", "Error" 등을 **대소문자 관계없이 검색**하면서 줄 번호 출력

2) 단어 단위 검색 + 파일 이름만 출력

grep -w -l "error" *.log
- "error"라는 **완전한 단어**가 포함된 파일 이름만 출력

3) 특정 단어 제외 + 검색된 줄 개수 출력

grep -v -c "DEBUG" logfile.txt
- "DEBUG"가 포함되지 않은 줄의 개수를 출력

4) 특정 패턴 이후 3줄 출력 (-A 3)

grep -A 3 "error" logfile.txt
- "error"가 포함된 줄 이후 3줄을 추가로 출력

6. grep을 이용한 디렉토리 검색

1) 하위 디렉토리 포함하여 검색 (-r)

grep -r "error" /var/log/
- /var/log/ 디렉토리의 모든 파일에서 "error" 검색

2) 하위 디렉토리 포함 + 파일 이름만 출력 (-rl)

grep -rl "error" /var/log/
- "error"가 포함된 파일 이름만 출력

3) 심볼릭 링크를 포함하여 검색 (-R)

grep -R "error" /var/log/
- /var/log/에서 심볼릭 링크 파일까지 포함하여 검색

7. grep과 정규 표현식 (Extended grep)

기본 grep은 **기본 정규 표현식(BRE)**만 지원
**확장 정규 표현식(ERE, grep -E)**을 사용하면 더 강력한 패턴 매칭 가능

정규식 패턴 설명 예제
^error "error"로 시작하는 줄 grep "^error" logfile.txt
error$ "error"로 끝나는 줄 grep "error$" logfile.txt
[0-9] 숫자가 포함된 줄 grep "[0-9]" logfile.txt
[A-Za-z] 알파벳이 포함된 줄 grep "[A-Za-z]" logfile.txt
\berror\b 완전한 "error" 단어 검색 grep -w "error" logfile.txt
error\|warning "error" 또는 "warning" 검색 grep -E "error|warning" logfile.txt
(foo|bar) "foo" 또는 "bar" 검색 grep -E "(foo|bar)" logfile.txt
[[:digit:]] 숫자 검색 grep "[[:digit:]]" logfile.txt

8. 정리

  • grep은 텍스트에서 특정 패턴을 검색하는 강력한 명령어
  • 옵션을 조합하면 더욱 강력한 검색이 가능
  • 디렉토리 검색을 통해 하위 폴더 내 파일에서도 문자열 검색 가능
  • 정규 표현식을 활용하면 복잡한 패턴도 쉽게 찾을 수 있음
  • grep은 로그 분석, 시스템 모니터링, 파일 검색 등 다양한 곳에서 사용

쉘 스크립트에서 데이터 필터링이 필요할 때 grep을 적극 활용하면 업무 효율성이 증가 🚀
