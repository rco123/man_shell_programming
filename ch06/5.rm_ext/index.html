여러 개의 예외 파일을 제외하고 삭제하는 방법

1. 기본 명령어 (ls | grep -v "important.txt" | xargs rm)의 문제점

ls | grep -v "important.txt" | xargs rm

문제점

  • "important.txt" 하나만 제외하고 삭제 가능
  • 여러 개의 파일을 제외하려면 grep -v를 여러 번 사용하거나 정규식을 사용해야 함

2. 여러 개의 파일을 제외하고 삭제하는 방법

방법 1: grep -v -E를 사용하여 여러 개의 파일 제외

ls | grep -v -E "important1.txt|important2.txt|important3.txt" | xargs rm

설명

  • grep -v -E "file1|file2|file3" → "file1", "file2", "file3"를 제외하고 출력
  • xargs rm → 남은 파일만 삭제

📄 디렉토리 내 파일 목록 

important1.txt
important2.txt
important3.txt
delete1.txt
delete2.txt
delete3.txt

실행 결과

deleted delete1.txt
deleted delete2.txt
deleted delete3.txt
(important1.txt, important2.txt, important3.txt는 삭제되지 않음)

방법 2: find를 사용하여 특정 파일 제외

find . -type f ! -name "important1.txt" ! -name "important2.txt" ! -name "important3.txt" -delete

설명

  • -type f → 파일만 검색
  • ! -name "important1.txt" → "important1.txt" 제외
  • ! -name "important2.txt" → "important2.txt" 제외
  • ! -name "important3.txt" → "important3.txt" 제외
  • -delete → 남은 파일 삭제

📄 디렉토리 내 파일 목록 

important1.txt
important2.txt
important3.txt
delete1.txt
delete2.txt
delete3.txt

실행 결과

deleted delete1.txt
deleted delete2.txt
deleted delete3.txt
(important1.txt, important2.txt, important3.txt는 삭제되지 않음)

방법 3: rm을 실행하기 전에 grep -F로 여러 개의 파일 제외

ls | grep -F -x -v -f exclude_list.txt | xargs rm

설명

  • exclude_list.txt에 삭제하지 않을 파일 목록 작성
  • grep -F -x -v -f exclude_list.txt → 리스트에 있는 파일 제외
  • xargs rm → 남은 파일 삭제

📄 exclude_list.txt 

important1.txt
important2.txt
important3.txt
📄 디렉토리 내 파일 목록 
important1.txt
important2.txt
important3.txt
delete1.txt
delete2.txt
delete3.txt

실행 결과

deleted delete1.txt
deleted delete2.txt
deleted delete3.txt
(important1.txt, important2.txt, important3.txt는 삭제되지 않음)

3. 정리

방법 명령어 설명
단일 파일 제외 ls | grep -v "important.txt" | xargs rm "important.txt" 제외하고 삭제
여러 개 파일 제외
(grep -E)		 ls | grep -v -E "file1|file2|file3" | xargs rm 여러 개 파일 제외
find 사용 find . -type f ! -name "file1" ! -name "file2" -delete 더 효율적인 파일 제외 삭제
파일 목록을 별도
파일에 저장		 ls | grep -F -x -v -f exclude_list.txt | xargs rm 제외할 파일을 exclude_list.txt에 저장하고 삭제
