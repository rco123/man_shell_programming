grep 정규식을 이용한 검색

1. grep에서 정규식 사용하기

grep은 기본적으로 정규 표현식(Regular Expression, regex)**을 사용하여 패턴 검색이 가능
- 기본 정규식(Basic Regular Expressions, BRE) - 확장 정규식(Extended Regular Expressions, ERE) → **grep -E 또는 egrep 사용

2. grep 정규식 사용법

1) . (임의의 한 문자 매칭)

grep -E "h.llo" filename.txt

설명

  • "h.llo" → "hello", "hallo", "hxllo" 등과 매칭 (h와 llo 사이에 임의의 한 글자가 있는 경우)

예제

📄 파일 내용 (filename.txt) 

hello
hallo
hxllo
hillo

실행 결과

hello
hallo
hxllo
hillo

2) ^ (문장 시작)

grep -E "^hello" filename.txt

설명

  • "^hello" → **"hello"로 시작하는 줄**만 검색

예제

📄 파일 내용 

hello world
this is hello
hello123

실행 결과

hello world
hello123
(문장 시작이 "hello"인 줄만 출력)

3) $ (문장 끝)

grep -E "world$" filename.txt

설명

  • "world$" → **"world"로 끝나는 줄**만 검색

예제

📄 파일 내용 

hello world
this is world
worldwide

실행 결과

hello world
this is world
("world"로 끝나는 줄만 출력)

4) * (앞 문자 0번 이상 반복)

grep -E "ho*t" filename.txt

설명

  • "ho*t" → "h" 다음에 "o"가 0번 이상 반복되고 "t"가 오는 패턴
  • "ht", "hot", "hoot", "hooooooot" 등이 검색됨

예제

📄 파일 내용 

ht
hot
hoot
hooooooot

실행 결과

ht
hot
hoot
hooooooot

5) + (앞 문자 1번 이상 반복)

grep -E "ho+t" filename.txt

설명

  • "ho+t" → "h" 다음에 "o"가 **1번 이상 반복**되고 "t"가 오는 패턴
  • "hot", "hoot", "hooooooot" 등이 검색됨
  • "ht"는 "o"가 없으므로 검색되지 않음

실행 결과

hot
hoot
hooooooot

6) ? (앞 문자 0번 또는 1번)

grep -E "colou?r" filename.txt

설명

  • "colou?r" → "u"가 있어도 되고 없어도 됨
  • 즉, "color", "colour" 둘 다 검색됨

예제

📄 파일 내용 

color
colour
colouur

실행 결과

color
colour
("colouur"는 "u"가 두 번 있어서 검색되지 않음)

7) {n,m} (앞 문자를 n~m번 반복)

grep -E "o{2,4}" filename.txt

설명

  • "o{2,4}" → "o"가 최소 2번, 최대 4번 반복
  • "oo", "ooo", "oooo" 검색됨

예제

📄 파일 내용 

o
oo
ooo
oooo
ooooo

실행 결과

oo
ooo
oooo
("o"는 한 번만 있어서 제외, "ooooo"는 다섯 번이라 제외)

8) | (OR 연산)

grep -E "cat|dog" filename.txt

설명

  • "cat|dog" → "cat" 또는 "dog"가 포함된 줄 검색

예제

📄 파일 내용 

I have a cat.
I love my dog.
Cats are cute.

실행 결과

I have a cat.
I love my dog.
("Cats"는 대소문자 구별 때문에 검색되지 않음 → -i 추가하면 가능)

9) [ ] (문자 집합)

grep -E "gr[aeiou]y" filename.txt

설명

  • "gr[aeiou]y" → "gray", "grey" 등 gr 다음에 모음이 오고 y로 끝나는 경우 검색

예제

📄 파일 내용 

gray
grey
gry

실행 결과

gray
grey

10) \b (단어 경계)

grep -E "\bhello\b" filename.txt

설명

  • \bhello\b → "hello"가 **독립된 단어로 존재하는 경우**만 검색
  • "xxhello"나 "helloxx"는 검색되지 않음

예제

📄 파일 내용 

hello
xxhello
hello world
helloxx

실행 결과

hello
hello world
("xxhello", "helloxx"는 제외됨)

3. 정규식 옵션 조합 예제

1) ^ + $ → 전체 줄이 특정 문자와 일치

grep -E "^hello$" filename.txt
- "hello"만 포함된 줄 검색 (앞뒤에 공백이 없어야 함)

2) -i + 정규식 → 대소문자 무시

grep -i -E "\bhello\b" filename.txt
- "hello", "Hello", "HELLO" 등 대소문자 관계없이 단어 검색

3) -r + 정규식 → 하위 디렉토리 포함 검색

grep -r -E "error|fail" /var/log/
- /var/log/ 디렉토리의 모든 파일에서 "error" 또는 "fail" 포함된 줄 검색

4. 정리

정규식 설명 예제
. 임의의 한 문자 "h.llo" → "hello", "hallo"
^ 문장 시작 "^hello" → "hello world"
$ 문장 끝 "world$" → "hello world"
* 앞 문자 0번 이상 반복 "ho*t" → "ht", "hot", "hoot"
+ 앞 문자 1번 이상 반복 "ho+t" → "hot", "hoot"
? 앞 문자 0 또는 1회 "colou?r" → "color", "colour"
{n,m} 앞 문자 n~m회 반복 "o{2,4}" → "oo", "ooo", "oooo"
| OR 연산 "cat|dog" → "cat", "dog"
[ ] 문자 집합 "gr[aeiou]y" → "gray", "grey"
\b 단어 경계 "\bhello\b" → "hello world"

정규 표현식을 활용하면 강력한 텍스트 필터링 및 데이터 추출이 가능 🚀
