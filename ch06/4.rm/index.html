rm 명령어 개요 및 사용법

1. rm이란?

  • rm (remove)은 파일 또는 디렉토리를 삭제하는 명령어
  • 삭제된 파일은 복구가 어렵기 때문에 주의해야 함
  • 특정 파일을 제외하고 삭제하는 방법도 가능

2. rm 기본 문법

rm [옵션] 파일명
- [옵션] → 삭제 방식 지정 - [파일명] → 삭제할 파일 또는 디렉토리

3. rm 주요 옵션

옵션 설명 예제
-f 강제 삭제 (파일이 없어도 오류 메시지 출력 안 함) rm -f file.txt
-i 삭제 확인 메시지 표시 (안전모드) rm -i file.txt
-r 디렉토리 및 하위 파일까지 삭제 (재귀 삭제) rm -r folder/
-d 빈 디렉토리만 삭제 rm -d empty_folder/
-v 삭제되는 파일 표시 (verbose) rm -v file.txt
--preserve-root 루트 디렉토리(/) 보호 (기본값) rm --preserve-root -rf / (실행 안 됨)

4. rm 사용 예제

1) 기본적인 파일 삭제

rm file.txt
- file.txt 삭제

2) 삭제 확인 메시지를 표시하며 삭제 (-i)

rm -i file.txt

출력 예시

rm: remove regular file 'file.txt'? y
- 사용자가 y를 입력해야 파일이 삭제됨

3) 여러 개의 파일 삭제

rm file1.txt file2.txt file3.txt
- file1.txt, file2.txt, file3.txt 삭제

4) 특정 확장자의 모든 파일 삭제

rm *.log
- 현재 디렉토리의 모든 .log 파일 삭제

5) 디렉토리와 하위 파일을 포함하여 삭제 (-r)

rm -r my_folder/
- my_folder/와 그 안의 모든 파일 삭제
- 주의: 삭제된 파일은 복구하기 어려움!

6) 강제 삭제 (-f)

rm -rf my_folder/
- 삭제 확인 없이 강제 삭제 (-f 강제, -r 재귀)

7) 삭제되는 파일을 확인하면서 삭제 (-v)

rm -rv my_folder/

출력 예시

removed 'my_folder/file1.txt'
removed 'my_folder/file2.txt'
removed directory 'my_folder'
- 어떤 파일이 삭제되는지 확인 가능

5. 특정 파일을 제외하고 삭제하는 방법

1) find와 rm을 조합하여 특정 파일 제외

find . -type f ! -name "important.txt" -delete

설명

  • find . -type f → 현재 디렉토리의 모든 파일 찾기
  • ! -name "important.txt" → "important.txt"는 제외
  • -delete → 검색된 파일 삭제

2) 여러 개의 특정 파일 제외하고 삭제

find . -type f ! -name "important1.txt" ! -name "important2.txt" -delete

설명

  • "important1.txt" 및 "important2.txt"를 제외한 모든 파일 삭제

3) 특정 확장자 제외하고 삭제

find . -type f ! -name "*.log" -delete

설명

  • .log 파일은 남기고, 나머지 모든 파일 삭제

4) rm과 grep을 조합하여 특정 파일 제외

ls | grep -v "important.txt" | xargs rm

설명

  • ls → 현재 디렉토리 파일 목록 출력
  • grep -v "important.txt" → "important.txt"를 제외한 파일 목록 필터링
  • xargs rm → 필터링된 파일만 삭제

6. rm을 사용할 때 주의할 점

1) rm -rf / 실행 금지!

rm -rf /
- 루트 디렉토리를 삭제하면 시스템이 완전히 망가짐 - 최신 리눅스 배포판에서는 --preserve-root 기본 활성화로 보호됨

2) 특정 디렉토리에서만 rm -rf 실행

rm -rf /home/user/temp/
- 특정 디렉토리 안에서만 실행해야 안전

3) 실수 방지를 위해 rm -i 또는 trash-cli 사용

rm -i file.txt
- 삭제 전 확인 메시지 표시 (안전모드)

trash-put file.txt
- trash-cli 패키지를 설치하면 휴지통으로 이동 가능

7. 정리

명령어 설명
rm file.txt 파일 삭제
rm -i file.txt 삭제 전 확인
rm -r my_folder/ 폴더 및 하위 파일 삭제
rm -rf my_folder/ 강제 삭제
find . -type f ! -name "important.txt" -delete 특정 파일 제외하고 삭제
rm -rv my_folder/ 삭제되는 파일 확인
  • rm은 삭제된 파일을 복구하기 어려우므로 주의해야 함
  • 특정 파일을 제외하고 삭제하려면 find와 ! -name 조합
  • 실수 방지를 위해 rm -i 또는 trash-cli 사용 추천 🚀
