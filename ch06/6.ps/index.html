PS

"ps" 명령어는 현재 시스템에서 실행 중인 프로세스들의 상태를 확인하는 데 사용되는 기본 유틸리티입니다. 이는 시스템 모니터링, 문제 해결, 리소스 사용 확인 등 여러 목적으로 사용됩니다.

주요 특징 및 개념

  • 프로세스 정보 표시:
    ps는 각 프로세스의 PID(프로세스 ID), 사용자, CPU/메모리 사용량, 실행 시간, 터미널 정보, 명령어 등 다양한 정보를 출력합니다.

  • 정적(snapshot) 정보:
    ps는 명령어 실행 시점의 프로세스 상태를 “스냅샷” 형태로 보여줍니다. 실시간 모니터링이 필요한 경우에는 top, htop과 같은 도구를 사용합니다.

일반적인 옵션들

  • BSD 스타일 옵션:
  • a: 현재 터미널에 종속되지 않은, 모든 사용자의 프로세스 출력
  • u: 사용자 중심의 출력 형식을 사용 (CPU, 메모리 사용량 등 포함)

  • x: 제어 터미널이 없는 프로세스도 포함하여 출력
    예시:

    ps aux
    이 명령은 모든 프로세스에 대해 상세 정보를 보여줍니다.

  • SysV 스타일 옵션:

  • -e: 모든 프로세스 출력 (ps -A 와 동일)

  • -f: 풀 포맷(full-format) 출력, 부모-자식 관계 등의 추가 정보를 포함
    예시:

    ps -ef
    이 명령은 프로세스 트리 구조와 함께 각 프로세스의 상세 정보를 보여줍니다.

  • 필터 및 정렬 옵션:

  • -p <pid>: 특정 PID에 해당하는 프로세스만 표시
  • --sort: 특정 컬럼(예: %CPU, %MEM 등)을 기준으로 정렬
    예시:
    ps -e --sort=-%cpu
    CPU 사용량이 높은 순으로 프로세스를 정렬하여 보여줍니다.

출력 컬럼 예시

ps 명령어의 출력은 보통 다음과 같은 컬럼들로 구성됩니다:

  • PID: 프로세스 식별 번호
  • USER: 프로세스를 소유한 사용자
  • %CPU / %MEM: CPU 및 메모리 사용률
  • VSZ / RSS: 가상 메모리 크기와 실제 사용 메모리
  • TTY: 프로세스가 연결된 터미널
  • STAT: 프로세스 상태 (예: S: sleep, R: running 등)
  • START: 프로세스 시작 시각
  • TIME: 누적 CPU 시간
  • COMMAND: 실행된 명령어

사용 예

  1. 모든 프로세스 목록 확인:

    ps aux
    모든 사용자 및 터미널과 상관없이 실행 중인 모든 프로세스를 상세히 출력합니다.

  2. 특정 사용자 프로세스 확인:

    ps -u jetson
    jetson 사용자가 소유한 프로세스만 표시합니다.

  3. 특정 PID의 프로세스 확인:

    ps -p 1234
    PID가 1234인 프로세스의 정보를 확인합니다.

  4. 정렬하여 출력:

    ps -eo pid,ppid,cmd,%mem,%cpu --sort=-%cpu
    PID, 부모 PID, 명령어, 메모리 및 CPU 사용률을 출력하며, CPU 사용률을 기준으로 내림차순 정렬합니다.

결론

ps 명령어는 시스템 상태를 이해하고 관리하는 데 필수적인 도구입니다. 다양한 옵션을 조합하여 원하는 정보를 필터링하거나 정렬할 수 있으며, 시스템 관리자는 이를 통해 프로세스 상태를 빠르게 파악하고, 필요시 특정 프로세스를 종료하거나 모니터링할 수 있습니다.

자세한 옵션 및 사용법은 man 페이지(man ps)를 참고하면 좋습니다.
