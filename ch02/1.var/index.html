쉘에서 변수 만들기

1. 변수 선언 및 할당

  • 변수는 변수명=값 형태로 선언
  • 변수명과 = 사이에 공백이 없어야 함 
name="Linux"
age=25

2. 변수 값 출력

  • $변수명 형태로 변수 값을 참조 
echo $name
echo $age

3. 변수에 값 할당 후 변경 가능

  • 기존 변수 값을 새로운 값으로 변경 가능 
name="Bash"
echo $name  # 출력: Bash

4. 사용자 입력을 변수에 저장

  • read 변수명을 사용하여 사용자 입력을 받을 수 있음 
echo "이름을 입력하세요:"
read user_name
echo "입력한 이름: $user_name"

5. 환경 변수로 설정

  • export를 사용하여 변수 값을 현재 세션에서 유지 가능 
export PATH=$PATH:/new/path

6. 변수에 {} 사용하기

  • 변수를 다른 문자열과 함께 사용할 때 {}를 사용하여 변수 이름을 명확하게 구분할 수 있음
  • {} 없이 사용할 경우, 변수명이 잘못 해석될 수 있음 
name="Shell"
echo "Welcome to ${name}Scripting!"  # 출력: Welcome to ShellScripting!
echo "Welcome to $nameScripting!"    # 올바르게 해석되지 않음

쉘 변수는 스크립트 내에서 데이터 저장 및 활용에 필수적인 요소이며, 시스템 설정 및 자동화 작업에서도 널리 사용됨.
