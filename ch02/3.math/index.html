변수 산술 계산

1. 변수 산술 계산 개요

  • 쉘 스크립트에서는 $(()), expr, bc 등을 사용하여 산술 연산 수행 가능
  • 기본적으로 **정수 연산**을 지원하며, 소수점 연산은 bc 명령어 사용

2. 기본 산술 연산 (정수 계산)

설명

  • $(()) 또는 expr을 사용하여 덧셈, 뺄셈, 곱셈, 나눗셈 수행 가능
  • expr 사용 시 백틱(`) 또는 $()로 감싸야 하며, *는 \*로 이스케이프 필요

코드 예제

#!/bin/bash

# 변수 선언
num1=20
num2=5

# 산술 연산 수행
sum=$((num1 + num2))         # 덧셈
diff=$((num1 - num2))        # 뺄셈
prod=$((num1 * num2))        # 곱셈
quot=$((num1 / num2))        # 나눗셈
mod=$((num1 % num2))         # 나머지 연산

# 결과 출력
echo "덧셈: $num1 + $num2 = $sum"
echo "뺄셈: $num1 - $num2 = $diff"
echo "곱셈: $num1 * $num2 = $prod"
echo "나눗셈: $num1 / $num2 = $quot"
echo "나머지: $num1 % $num2 = $mod"

실행 결과

덧셈: 20 + 5 = 25  
뺄셈: 20 - 5 = 15  
곱셈: 20 * 5 = 100  
나눗셈: 20 / 5 = 4  
나머지: 20 % 5 = 0

3. expr을 사용한 산술 연산

설명

  • expr 명령어를 사용하여 산술 연산 수행 가능
  • * 연산자는 \*로 이스케이프 처리해야 함

코드 예제

#!/bin/bash

num1=15
num2=3

sum=$(expr $num1 + $num2)
diff=$(expr $num1 - $num2)
prod=$(expr $num1 \* $num2)
quot=$(expr $num1 / $num2)
mod=$(expr $num1 % $num2)

echo "덧셈: $sum"
echo "뺄셈: $diff"
echo "곱셈: $prod"
echo "나눗셈: $quot"
echo "나머지: $mod"

실행 결과

덧셈: 18  
뺄셈: 12  
곱셈: 45  
나눗셈: 5  
나머지: 0

4. 실수(소수점) 연산 (bc 사용)

설명

  • bc 명령어를 사용하면 소수점 연산이 가능
  • scale=n을 설정하여 소수점 자리수를 지정할 수 있음

코드 예제

#!/bin/bash

num1=10.5
num2=2.3

sum=$(echo "$num1 + $num2" | bc)
diff=$(echo "$num1 - $num2" | bc)
prod=$(echo "$num1 * $num2" | bc)
quot=$(echo "scale=2; $num1 / $num2" | bc)  # 소수점 2자리까지 표시

echo "덧셈: $sum"
echo "뺄셈: $diff"
echo "곱셈: $prod"
echo "나눗셈: $quot"

실행 결과

덧셈: 12.8  
뺄셈: 8.2  
곱셈: 24.15  
나눗셈: 4.56

5. 증가 및 감소 연산

설명

  • ++ 및 -- 연산자를 사용하여 값 증가 또는 감소 가능
  • +=, -= 등의 복합 대입 연산자도 사용 가능

코드 예제

#!/bin/bash

count=10

((count++))  # 1 증가
echo "count 증가 후: $count"

((count--))  # 1 감소
echo "count 감소 후: $count"

((count += 5))  # 5 증가
echo "count += 5: $count"

((count -= 3))  # 3 감소
echo "count -= 3: $count"

실행 결과

count 증가 후: 11  
count 감소 후: 10  
count += 5: 15  
count -= 3: 12

6. 변수 산술 계산 정리

  • $(())를 사용하면 기본적인 정수 연산 가능
  • expr 명령어를 사용하면 연산 가능하지만 * 이스케이프 필요
  • bc 명령어를 사용하면 실수 연산 및 소수점 계산 가능
  • ++, --, +=, -= 등을 활용하여 값 변경 가능

쉘에서 변수 산술 계산을 활용하면 반복적인 연산을 자동화할 수 있으며, 데이터 처리 및 시스템 관리 스크립트에서도 유용하게 사용됨. 🚀
