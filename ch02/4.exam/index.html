변수를 이용한 간단한 실습

1. 변수 선언 및 출력

설명

  • 변수를 선언하고 값을 할당한 후 echo 명령어로 출력하는 기본적인 실습

코드 예제

#!/bin/bash

# 변수 선언
greeting="Hello"
name="Bash"

# 변수 출력
echo "$greeting, $name!"

실행 결과

Hello, Bash!

2. 사용자 입력을 변수에 저장하고 출력

설명

  • read 명령어를 사용하여 사용자의 입력을 변수에 저장하고 출력하는 실습

코드 예제

#!/bin/bash

# 사용자 입력 받기
echo "이름을 입력하세요:"
read user_name

# 입력한 이름 출력
echo "환영합니다, $user_name!"

실행 예시

이름을 입력하세요:
Alice
환영합니다, Alice!

3. 변수 연산 (정수 계산)

설명

  • $(()) 또는 expr을 사용하여 변수에 저장된 숫자를 연산하는 실습

코드 예제

#!/bin/bash

# 숫자 변수 선언
num1=10
num2=5

# 덧셈 연산
sum=$((num1 + num2))

# 결과 출력
echo "$num1 + $num2 = $sum"

실행 결과

10 + 5 = 15

4. 변수와 환경 변수 활용

설명

  • export를 사용하여 환경 변수를 설정하고 확인하는 실습

코드 예제

#!/bin/bash

# 환경 변수 설정
export MY_VAR="This is an environment variable"

# 다른 스크립트에서 환경 변수 사용 가능
echo "환경 변수 값: $MY_VAR"

실행 결과

환경 변수 값: This is an environment variable

위 실습을 통해 변수 선언, 사용자 입력 저장, 연산 활용, 환경 변수 설정 등의 기본적인 개념을 익힐 수 있음.
