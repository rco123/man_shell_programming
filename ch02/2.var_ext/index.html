변수확장

$(( )) 와 $( ) 을 이용한 기능 확장을 수행한다. 쉘 스크립트에서 두 기능을 함께 사용하면 명령어 실행 결과를 활용한 연산 및 자동화 작업이 가능 하게한다.

  • $(( )) → 산술 확장 (Arithmetic Expansion)

    • 쉘에서 정수 계산을 수행하는 기능
    • 덧셈, 뺄셈, 곱셈, 나눗셈 등 기본적인 **산술 연산**을 지원

  • $( ) → 명령어 치환 (Command Substitution)

    • 쉘에서 **명령어를 실행하고 그 결과를 변수에 저장**하는 기능
    • echo, date, pwd 등 쉘 명령어 실행 결과를 문자열로 반환

두 개념의 정리 | 구분 | 명칭 | 기능 | |------|------|------| | $(( )) | 산술 확장 (Arithmetic Expansion) | 정수 연산 수행 | | $( ) | 명령어 치환 (Command Substitution) | 쉘 명령어 실행 후 결과 반환 |

1. $(( )) - 산술 연산 (Arithmetic Expansion)

  • 정수 연산(덧셈, 뺄셈, 곱셈, 나눗셈 등)을 수행하는 기능
  • +, -, *, /, %, ++, -- 등의 연산자를 지원
  • 정수 계산만 가능하며, 소수점 연산은 지원하지 않음

사용 예제

#!/bin/bash

num1=10
num2=3

# 산술 연산
sum=$((num1 + num2))
diff=$((num1 - num2))
prod=$((num1 * num2))
quot=$((num1 / num2))  # 정수 나눗셈
mod=$((num1 % num2))

echo "덧셈: $sum"
echo "뺄셈: $diff"
echo "곱셈: $prod"
echo "나눗셈(정수): $quot"
echo "나머지: $mod"

실행 결과

덧셈: 13  
뺄셈: 7  
곱셈: 30  
나눗셈(정수): 3  
나머지: 1

2. $( ) - 명령어 실행 (Command Substitution)

  • **쉘 명령어(Command)를 실행하고 그 결과를 변수에 저장**하는 기능
  • echo, ls, pwd, date, whoami 등 외부 명령어 실행 가능
  • 명령어의 실행 결과를 문자열로 반환

사용 예제

#!/bin/bash

# 명령어 실행 결과 저장
current_date=$(date)
current_dir=$(pwd)
user_name=$(whoami)

echo "현재 날짜: $current_date"
echo "현재 디렉토리: $current_dir"
echo "현재 사용자: $user_name"

실행 결과

현재 날짜: Mon Feb 26 14:30:00 UTC 2025  
현재 디렉토리: /home/user  
현재 사용자: user

3. $(( ))와 $( )의 차이점

기능 $(( )) $( )
역할 산술 연산 수행 명령어 실행 결과 반환
사용 용도 정수 계산 (덧셈, 뺄셈, 곱셈 등) 쉘 명령어 실행 및 결과 저장
입력 값 변수 또는 숫자 외부 명령어 (ls, date, whoami 등)
출력 값 정수 결과 문자열 결과
소수점 계산 지원하지 않음 bc 명령어를 사용하면 가능

4. 두 기능을 함께 사용하기

  • $( )로 명령어 실행 후, $(( ))로 연산 수행 가능

예제

#!/bin/bash

# 현재 날짜에서 연도만 추출하여 계산
current_year=$(date +%Y)
birth_year=1995

age=$((current_year - birth_year))

echo "현재 연도: $current_year"
echo "태어난 연도: $birth_year"
echo "나이: $age"

실행 결과

현재 연도: 2025  
태어난 연도: 1995  
나이: 30

5. 정리

  • **$(( ))는 정수 연산을 수행하는 기능**이며, 연산자를 사용하여 계산 가능
  • $( )는 쉘 명령어를 실행하고 그 결과를 변수에 저장하는 기능
  • 두 기능을 함께 사용하면 명령어 실행 결과를 활용한 연산이 가능

쉘 스크립트에서 $(( ))와 $( )를 적절히 활용하면 **산술 연산과 명령어 실행을 조합한 자동화 스크립트 작성이 가능**함. 🚀
