배열

Bash에서는 두 종류의 배열을 사용할 수 있습니다. 하나는 **일반 배열(인덱스 배열)**이고, 다른 하나는 **연관 배열(associative array)**입니다. 두 배열 모두 여러 값을 저장할 수 있지만, 인덱스 방식이 다릅니다.

1. 일반 배열 (Indexed Array)

일반 배열은 숫자 인덱스를 사용하여 값을 저장합니다. 기본 인덱스는 0부터 시작하며, 배열의 각 요소는 순서대로 저장됩니다.

선언 및 초기화

  1. 선언 및 값 할당
    # 한 줄에 여러 값을 넣어서 초기화
fruits=("apple" "banana" "cherry")
  2. 개별 요소에 값 할당
    # 배열 선언 후 개별 요소에 값 할당
fruits[0]="apple"
fruits[1]="banana"
fruits[2]="cherry"

요소 접근 및 출력

  • 배열 전체의 요소 출력:
    echo "${fruits[@]}"
  • 배열의 특정 요소 출력 (예: 인덱스 1):
    echo "${fruits[1]}"

배열 길이 확인

  • 배열에 저장된 요소 개수:
    echo "${#fruits[@]}"

C 스타일의 for 루프를 사용하여 순회

for (( i=0; i < ${#fruits[@]}; i++ )); do
    echo "Fruit $i: ${fruits[i]}"
done

또는 일반 for 루프를 사용할 수도 있습니다.

for fruit in "${fruits[@]}"; do
    echo "$fruit"
done

2. 연관 배열 (Associative Array)

연관 배열은 숫자 인덱스 대신 **키(key)**를 사용하여 값을 저장합니다. Bash 4 이상에서 지원됩니다.

선언 및 초기화

연관 배열을 사용하기 전에 declare -A 명령을 사용하여 배열임을 선언해야 합니다.

declare -A person

이후, 키와 값을 할당합니다.

person[name]="Alice"
person[age]=30
person[city]="Seoul"

요소 접근 및 출력

  • 특정 키의 값 출력:

    echo "Name: ${person[name]}"
echo "Age: ${person[age]}"
echo "City: ${person[city]}"

  • 배열의 모든 키를 출력:

    echo "Keys: ${!person[@]}"
    여기서 ${!person[@]}는 연관 배열 person의 모든 키 목록을 반환합니다.

  • 배열의 모든 값을 출력:

    echo "Values: ${person[@]}"

연관 배열 순회

연관 배열의 각 요소를 순회할 때는 키 목록을 이용할 수 있습니다.

for key in "${!person[@]}"; do
    echo "Key: $key, Value: ${person[$key]}"
done

요약

  • 일반 배열(Indexed Array):
  • 인덱스: 0, 1, 2, …와 같은 숫자로 요소에 접근
  • 선언: fruits=("apple" "banana" "cherry")
  • 접근: ${fruits[index]}, 전체 출력은 ${fruits[@]}

  • 길이: ${#fruits[@]}

  • 연관 배열(Associative Array):

  • 키: 문자열(예: "name", "age", "city")를 사용
  • 선언: declare -A person
  • 할당: person[name]="Alice"
  • 접근: ${person[name]}, 키 목록은 ${!person[@]}, 값 목록은 ${person[@]}
  • 순회: for key in "${!person[@]}"; do ...; done

이와 같이 Bash에서는 상황에 맞게 일반 배열과 연관 배열을 사용하여 여러 데이터를 효율적으로 관리할 수 있습니다.
