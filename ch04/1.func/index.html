쉘 스크립트에서 함수 만들기

1. 함수(Function)의 개념

  • 쉘 스크립트에서 **함수(Function)**는 특정 명령어 그룹을 재사용할 수 있도록 정의하는 구조
  • **코드를 모듈화하고 가독성을 향상**시켜 유지보수 용이
  • 필요할 때마다 호출하여 실행 가능

2. 함수의 기본 구조

형식 1: function 키워드 사용

function 함수이름() {
    명령어
}

형식 2: function 키워드 없이 선언

함수이름() {
    명령어
}

두 가지 방법 모두 사용 가능하며, function 키워드는 선택 사항
대부분의 쉘에서는 function 없이도 함수 선언 가능

3. 함수 정의 및 호출

예제: 간단한 함수 작성 및 실행

#!/bin/bash

# 함수 선언
greet() {
    echo "안녕하세요! 쉘 스크립트 함수입니다."
}

# 함수 호출
greet

실행 결과

안녕하세요! 쉘 스크립트 함수입니다.

4. 함수에 인수(Argument) 전달

설명

  • 함수에 값을 전달하면 함수 내부에서 $1, $2, $3 등의 변수로 접근 가능
  • $#는 인수 개수를 나타내며, $@는 모든 인수를 의미

코드 예제

#!/bin/bash

# 함수 정의
greet_user() {
    echo "안녕하세요, $1님!"
    echo "오늘의 날짜: $(date)"
}

# 함수 호출 (인수 전달)
greet_user "홍길동"

실행 결과

안녕하세요, 홍길동님!
오늘의 날짜: 2025-02-26

5. 여러 개의 인수 처리

설명

  • $0 → 함수 이름 자체
  • $1, $2, $3 … 각각 첫 번째, 두 번째, 세 번째 인수를 의미
  • $# → 전달된 인수의 개수
  • $@ → 모든 인수 리스트

코드 예제

#!/bin/bash

# 함수 정의
print_info() {
    echo "첫 번째 인수: $1"
    echo "두 번째 인수: $2"
    echo "총 인수 개수: $#"
    echo "전체 인수 목록: $@"
}

# 함수 호출
print_info "Linux" "Shell"

실행 결과

첫 번째 인수: Linux
두 번째 인수: Shell
총 인수 개수: 2
전체 인수 목록: Linux Shell

6. 함수에서 반환값 사용 (return과 echo)

설명

  • return 키워드는 함수 실행 후 종료 상태 코드(0~255)를 반환
  • 일반적인 함수 반환값은 echo를 이용하여 출력 후 변수에 저장

코드 예제 (반환 코드 사용)

#!/bin/bash

# 함수 정의
check_number() {
    if [ $1 -gt 10 ]; then
        return 0  # 성공
    else
        return 1  # 실패
    fi
}

# 함수 호출 및 반환값 확인
check_number 15
echo "리턴값: $?"  # $? → 마지막 실행 명령의 종료 상태 코드 출력

실행 결과

리턴값: 0

코드 예제 (echo를 사용한 반환값 처리)

#!/bin/bash

# 함수 정의
sum() {
    result=$(( $1 + $2 ))
    echo $result
}

# 함수 호출 후 결과 저장
total=$(sum 10 20)

# 출력
echo "합계: $total"

실행 결과

합계: 30

7. 지역 변수와 전역 변수

설명

  • 기본적으로 함수 내부에서 선언한 변수는 **전역 변수**로 동작
  • local 키워드를 사용하면 **지역 변수**로 선언 가능

코드 예제 (전역 변수와 지역 변수 비교)

#!/bin/bash

# 전역 변수
name="Shell"

change_name() {
    local name="Bash"  # 지역 변수
    echo "함수 내부: $name"
}

echo "함수 호출 전: $name"
change_name
echo "함수 호출 후: $name"  # 전역 변수 값 유지

실행 결과

함수 호출 전: Shell
함수 내부: Bash
함수 호출 후: Shell

local을 사용하지 않으면 함수 내부에서 변경된 값이 전역 변수에도 영향을 줌

8. 함수에서 명령어 실행 및 명령어 치환

설명

  • 함수 내에서 명령어 실행 가능
  • 명령어 실행 결과를 함수 반환값으로 활용 가능

코드 예제

#!/bin/bash

# 시스템 정보 출력 함수
system_info() {
    echo "현재 사용자: $(whoami)"
    echo "현재 디렉토리: $(pwd)"
    echo "시스템 업타임: $(uptime -p)"
}

# 함수 호출
system_info

실행 결과

현재 사용자: user
현재 디렉토리: /home/user
시스템 업타임: up 2 hours, 15 minutes

9. 함수에서 조건문과 반복문 사용

설명

  • 함수 내부에서 조건문(if, case) 및 반복문(for, while) 사용 가능

코드 예제 (반복문 사용)

#!/bin/bash

# 반복문을 이용하여 리스트 출력
print_numbers() {
    for num in {1..5}; do
        echo "숫자: $num"
    done
}

# 함수 호출
print_numbers

실행 결과

숫자: 1
숫자: 2
숫자: 3
숫자: 4
숫자: 5

정리

  • 함수는 function 함수명() {} 또는 함수명() {} 형식으로 선언
  • 함수 호출 시 함수이름 입력
  • 인수는 $1, $2, $@, $#로 접근 가능
  • 반환값은 return (0~255) 또는 echo로 전달
  • local을 사용하면 지역 변수 선언 가능
  • 함수 내부에서 조건문, 반복문 및 명령어 실행 가능

쉘 함수는 **스크립트의 재사용성을 높이고 코드 구조를 개선**하는 중요한 기능으로, 다양한 자동화 작업에 활용 가능함. 🚀
