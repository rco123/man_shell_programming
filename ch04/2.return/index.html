함수의 리턴값을 받아서 다시 사용하는 함수 예제

1. echo를 사용하여 반환값을 다른 함수에서 활용

설명

  • 함수에서 echo를 사용하여 값을 반환하면 $( )로 해당 값을 받아서 다른 함수에서 활용 가능

코드 예제

#!/bin/bash

# 두 숫자의 합을 구하는 함수
sum() {
    result=$(( $1 + $2 ))  # 계산 수행
    echo $result           # 결과 출력 (return 역할)
}

# 합을 받아 출력하는 함수
display_sum() {
    total=$(sum $1 $2)  # sum 함수의 결과를 변수에 저장
    echo "두 숫자의 합: $total"
}

# 함수 호출
display_sum 10 20

실행 결과

두 숫자의 합: 30

2. return을 사용하여 종료 상태 코드 전달 후 활용

설명

  • return은 0~255 사이의 값을 반환 (일반적인 연산 결과를 전달하기에는 제한적)
  • 주로 성공(0) 또는 실패(1) 같은 상태 코드 반환에 사용

코드 예제

#!/bin/bash

# 입력값이 10보다 큰지 확인하는 함수
check_number() {
    if [ $1 -gt 10 ]; then
        return 0  # 성공 (10보다 큼)
    else
        return 1  # 실패 (10 이하)
    fi
}

# 결과를 받아 메시지 출력하는 함수
validate_number() {
    check_number $1  # check_number 함수 실행
    result=$?        # 종료 상태 코드 저장

    if [ $result -eq 0 ]; then
        echo "$1은(는) 10보다 큽니다."
    else
        echo "$1은(는) 10보다 작거나 같습니다."
    fi
}

# 함수 호출
validate_number 15
validate_number 5

실행 결과

15은(는) 10보다 큽니다.
5은(는) 10보다 작거나 같습니다.

3. 두 개의 함수를 사용하여 반환값을 활용하는 예제

설명

  • 첫 번째 함수에서 문자열을 반환하고, 두 번째 함수에서 이를 변형하여 출력

코드 예제

#!/bin/bash

# 사용자 환영 메시지를 생성하는 함수
get_welcome_message() {
    echo "안녕하세요, $1님!"
}

# 환영 메시지를 받아서 추가 메시지와 함께 출력하는 함수
display_welcome() {
    message=$(get_welcome_message "$1")  # 메시지 저장
    echo "$message 당신의 방문을 환영합니다!"
}

# 함수 호출
display_welcome "홍길동"

실행 결과

안녕하세요, 홍길동님! 당신의 방문을 환영합니다!

정리

  • echo를 사용하면 연산 결과나 문자열을 반환하고 다른 함수에서 활용 가능
  • return은 주로 상태 코드(성공/실패)를 반환하는 용도로 사용
  • 반환된 값을 다른 함수에서 받아서 조합하거나 새로운 연산을 수행 가능

쉘 스크립트에서 함수 간 데이터 전달을 효과적으로 활용하면 자동화 및 로직을 더욱 유연하게 구현할 수 있음 🚀
