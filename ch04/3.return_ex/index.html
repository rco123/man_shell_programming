$() 안에서 함수 실행해야 하는 이유

total=$(sum $1 $2) 와 같이 함수의 반환값을 변수에 저장하려면 $() 안에서 실행해야 함.

1. $() 없이 실행할 경우

예제

#!/bin/bash

# 두 수의 합을 계산하는 함수
sum() {
    result=$(( $1 + $2 ))  # 계산 수행
    echo $result           # 결과 출력
}

# 함수 호출 (잘못된 방법)
sum 10 20
total=$result  # sum 함수 내부의 result 변수를 사용하려고 함

echo "두 숫자의 합: $total"

실행 결과

30
두 숫자의 합:
❌ 잘못된 이유
  • sum 10 20이 실행되었을 때 result=30이지만, 이 값은 함수 내부에서만 존재
  • total=$result를 통해 값을 저장하려 했지만, **result는 함수 내에서만 정의된 변수**이므로 total이 비어 있음

2. $()를 사용하여 함수 실행 (올바른 방법)

예제

#!/bin/bash

# 두 수의 합을 계산하는 함수
sum() {
    result=$(( $1 + $2 ))  # 계산 수행
    echo $result           # 결과 출력
}

# 함수 호출 (올바른 방법)
total=$(sum 10 20)  # sum 함수의 출력을 total에 저장

echo "두 숫자의 합: $total"

실행 결과

두 숫자의 합: 30
✅ 올바른 이유
  • $()를 사용하면 sum 함수의 echo 결과(30)를 total 변수에 저장
  • 즉, sum 10 20이 실행되면서 echo 30이 출력되고, $()가 이를 변수에 저장

3. backticks (\``) vs$()` 차이

쉘에서는 $() 대신 백틱(`)을 사용할 수도 있음.
하지만 $() 사용이 **더 가독성이 좋고 중첩 사용 가능**하기 때문에 권장됨. 

total=`sum 10 20`  # 백틱 사용 가능하지만, `$()`가 더 명확함
$()와 백틱(``) 차이 예제
echo $(echo $(date))  # 중첩 가능
echo `echo \`date\``  # 백틱 사용 시 복잡함

4. return을 사용한 함수는 $()로 값을 받을 수 없는 이유

쉘 스크립트에서 return은 함수의 종료 상태 코드(0~255)만 반환 가능.
따라서, return을 사용한 함수의 값을 $()로 받을 수 없음.

잘못된 예제 (return 사용)

sum() {
    return $(( $1 + $2 ))  # return은 0~255까지만 가능
}

total=$(sum 10 20)  # 잘못된 방식
echo "합계: $total"

올바른 예제 (echo 사용)

sum() {
    echo $(( $1 + $2 ))  # echo로 결과 반환
}

total=$(sum 10 20)  # 올바른 방식
echo "합계: $total"

5. 정리

  • $() 안에서 함수 실행해야 echo의 출력값을 변수에 저장 가능`
  • return은 함수 종료 상태 코드(0~255)만 반환하므로 $()와 함께 사용 불가
  • 백틱(`)도 가능하지만$()`가 더 가독성이 좋고 중첩 사용 가능
  • 값을 반환하려면 return 대신 echo를 사용해야 함

쉘 스크립트에서 $()를 활용하면 함수 결과를 변수에 저장하고 다양한 연산에 활용 가능 🚀
