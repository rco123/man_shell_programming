  • 5. 명령어
  • 5.1 표준입출력

표준 입출력 (Standard I/O)와 파일 디스크립터 번호 (0, 1, 2)

쉘에서는 **표준 입출력(standard I/O)**을 사용하여 프로그램과 사용자 간 데이터를 주고받음.
각 입출력 스트림에는 고유한 **파일 디스크립터(File Descriptor, FD) 번호**가 할당됨.

1. 표준 입출력 스트림과 파일 디스크립터 번호

파일 디스크립터(FD) 스트림 이름 설명 기본 대상
0 표준 입력 (stdin) 사용자 입력을 받는 스트림 키보드
1 표준 출력 (stdout) 프로그램 실행 결과를 출력하는 스트림 터미널
2 표준 오류 (stderr) 오류 메시지를 출력하는 스트림 터미널

2. 표준 입력 (Standard Input, stdin, 파일 디스크립터 0)

  • 프로그램이 사용자로부터 입력을 받을 때 사용하는 스트림
  • 기본적으로 **키보드**에서 입력을 받음
  • < 리디렉션을 사용하여 파일에서 입력을 받을 수도 있음

예제 1: read를 사용한 표준 입력

#!/bin/bash
echo "이름을 입력하세요:"
read name  # 표준 입력 (키보드)
echo "입력된 이름: $name"

실행 결과

이름을 입력하세요:
Alice
입력된 이름: Alice

예제 2: 파일에서 표준 입력 받기 (< 리디렉션)

sort < names.txt
- names.txt 파일을 입력으로 받아 정렬하여 출력

3. 표준 출력 (Standard Output, stdout, 파일 디스크립터 1)

  • 프로그램 실행 결과를 출력하는 스트림
  • 기본적으로 터미널(화면)에 출력
  • > 또는 >> 리디렉션을 사용하여 파일에 저장 가능

예제 1: 기본적인 표준 출력

echo "Hello, World!"

실행 결과

Hello, World!
(터미널에 출력됨)

예제 2: 표준 출력을 파일로 리디렉션 (>, >>)

echo "로그 메시지" > log.txt  # 기존 내용 덮어쓰기
echo "추가 메시지" >> log.txt  # 기존 내용 유지하고 추가
- log.txt 파일에 "로그 메시지" 저장
- "추가 메시지"를 파일 끝에 추가

4. 표준 오류 (Standard Error, stderr, 파일 디스크립터 2)

  • 프로그램 실행 중 발생한 오류 메시지를 출력하는 스트림
  • 기본적으로 터미널(화면)에 출력
  • 2> 또는 2>> 리디렉션을 사용하여 파일로 저장 가능

예제 1: 존재하지 않는 파일 실행 (오류 발생)

ls nonexistentfile

실행 결과

ls: cannot access 'nonexistentfile': No such file or directory
(오류 메시지가 터미널에 출력됨)

예제 2: 표준 오류를 파일로 저장 (2>, 2>>)

ls nonexistentfile 2> error.log  # 오류 메시지를 error.log에 저장
ls anotherfile 2>> error.log  # 기존 오류 로그에 추가
- 2> → error.log에 오류 메시지 저장 (덮어쓰기)
- 2>> → error.log에 오류 메시지 추가

5. 표준 입출력 리디렉션 및 조합

1) 표준 출력과 표준 오류를 동시에 파일로 저장 (&>)

ls validfile nonexistentfile &> output.log
- output.log에 표준 출력과 표준 오류를 함께 저장

2) 표준 출력을 파일로 저장하고, 오류는 화면에 출력

ls validfile nonexistentfile > output.log 2>&1
- output.log → 표준 출력과 표준 오류를 함께 저장
- 2>&1 → 표준 오류(2)를 표준 출력(1)으로 합침

3) 표준 오류만 화면에서 숨기기 (2>/dev/null)

ls nonexistentfile 2>/dev/null
- 오류 메시지를 /dev/null로 보내서 화면에서 숨김

4) 표준 입력을 파일에서 가져오기 (<)

sort < names.txt
- names.txt 파일을 입력으로 받아 정렬하여 출력

5) 표준 입력, 출력, 오류를 조합한 예제

command < input.txt > output.txt 2> error.log
- input.txt → 표준 입력으로 사용
- output.txt → 표준 출력 저장
- error.log → 표준 오류 저장

6. 표준 입출력 정리

파일 디스크립터 스트림 설명 기본 대상 리디렉션
0 표준 입력 (stdin) 사용자 입력을 받는 스트림 키보드 <
1 표준 출력 (stdout) 프로그램 실행 결과를 출력하는 스트림 터미널 > (덮어쓰기), >> (추가)
2 표준 오류 (stderr) 오류 메시지를 출력하는 스트림 터미널 2>, 2>>

쉘 스크립트에서 **표준 입출력과 리디렉션을 활용하면 효율적인 데이터 처리 및 자동화 작업이 가능**함 🚀
