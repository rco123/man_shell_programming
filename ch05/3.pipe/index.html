파이프(|)를 사용한 여러 명령어 연결

1. | (파이프)란?

  • 한 명령어의 표준 출력을 다음 명령어의 표준 입력으로 전달하는 기능
  • 여러 명령을 연결하여 데이터를 가공하고 처리할 수 있음
  • 중간 파일을 생성하지 않고 데이터를 처리할 수 있어 효율적

2. 기본 문법

command1 | command2 | command3 ...
- command1의 출력이 command2의 입력이 되고,
- command2의 출력이 command3의 입력으로 연결됨

3. 파이프(|) 사용 예제

예제 1: ls와 grep을 사용한 파일 검색

ls -l | grep ".sh"

설명

  • ls -l → 현재 디렉토리의 파일 목록을 출력
  • grep ".sh" → .sh가 포함된 파일만 필터링

실행 결과

-rwxr-xr-x  1 user user  4096 Feb 26 10:00 script.sh
(현재 디렉토리에서 .sh 확장자를 가진 파일만 출력됨)

예제 2: ps와 grep을 사용하여 특정 프로세스 검색

ps aux | grep "apache"

설명

  • ps aux → 실행 중인 모든 프로세스를 출력
  • grep "apache" → apache가 포함된 프로세스만 필터링

실행 결과

www-data  1234  0.1  1.2  23456  5678 ?    S    14:30   0:00 apache2 -k start

예제 3: df와 awk를 사용하여 특정 필드만 출력

df -h | awk '{print $1, $5}'

설명

  • df -h → 디스크 사용량을 출력
  • awk '{print $1, $5}' → 파일 시스템과 사용량(%)만 출력

실행 결과

Filesystem Use%
/dev/sda1  45%
/dev/sdb2  32%

예제 4: cat과 sort를 사용하여 정렬

cat names.txt | sort

설명

  • cat names.txt → names.txt 파일 내용을 출력
  • sort → 알파벳 순서대로 정렬

실행 결과

Alice
Bob
Charlie
David

예제 5: ls, sort, head를 사용하여 가장 작은 파일 찾기

ls -l | sort -k5,5n | head -5

설명

  • ls -l → 파일 목록과 크기 출력
  • sort -k5,5n → 파일 크기(5번째 컬럼) 기준으로 오름차순 정렬
  • head -5 → 가장 작은 5개의 파일 출력

예제 6: find, xargs, wc를 사용하여 특정 파일 개수 세기

find . -type f -name "*.txt" | wc -l

설명

  • find . -type f -name "*.txt" → 현재 디렉토리에서 .txt 파일 검색
  • wc -l → 파일 개수 세기

실행 결과

15
(현재 디렉토리에 .txt 파일이 15개 있다는 의미)

예제 7: dmesg와 less를 사용하여 시스템 로그 확인

dmesg | less

설명

  • dmesg → 커널 로그 메시지 출력
  • less → 한 페이지씩 출력

예제 8: cat, grep, cut을 사용하여 특정 정보 추출

cat /etc/passwd | grep "root" | cut -d ":" -f1

설명

  • /etc/passwd에서 root가 포함된 행을 찾고,
  • cut을 사용하여 첫 번째 필드(사용자 이름)만 출력

실행 결과

root

4. 여러 개의 명령어를 조합한 복잡한 예제

예제 9: ps, sort, head를 사용하여 가장 많이 CPU를 사용하는 프로세스 찾기

ps aux | sort -k3,3nr | head -5

설명

  • ps aux → 실행 중인 모든 프로세스 출력
  • sort -k3,3nr → CPU 사용량(3번째 컬럼) 기준 내림차순 정렬
  • head -5 → CPU를 가장 많이 사용하는 상위 5개 프로세스 출력

예제 10: find, xargs, du를 사용하여 가장 큰 파일 찾기

find /var/log -type f -size +100M | xargs du -h | sort -hr | head -5

설명

  • /var/log 디렉토리에서 100MB 이상 파일 검색
  • xargs du -h → 파일 크기를 사람이 읽기 쉬운 형태로 표시
  • sort -hr → 크기 기준 내림차순 정렬
  • head -5 → 가장 큰 5개 파일 출력

5. |를 사용할 때 주의할 점

  1. 출력 형식이 올바른지 확인
  2. 예: ls -l의 경우, 첫 번째 줄(합계) 제거 필요

  3. 해결: ls -l | tail -n +2 (첫 줄 제외)

  4. 파일명을 안전하게 처리 (xargs vs -exec)

  5. xargs를 사용할 경우, 공백 포함된 파일명 문제 발생 가능

  6. 해결: find . -name "*.txt" -exec rm {} \;

  7. 성능 고려

  8. |를 지나치게 많이 사용하면 성능 저하 가능
  9. 대안: awk, sed를 활용하여 한 번에 처리

6. 정리

명령어 조합 설명
ls | grep "txt" 특정 파일 필터링
ps aux | sort -k3,3nr | head -5 CPU 사용량이 높은 프로세스 찾기
df -h | awk '{print $1, $5}' 디스크 사용량 필터링
find . -type f | wc -l 현재 디렉토리의 파일 개수 세기
dmesg | less 커널 로그 확인
cat file | sort | uniq -c | sort -nr 중복된 단어 개수 세기

쉘에서 |를 활용하면 **효율적으로 데이터를 가공하고 원하는 정보를 추출**할 수 있음 🚀
